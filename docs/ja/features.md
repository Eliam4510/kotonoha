# 機能

バージョン 0.31.0 の各機能の状況と確認方法です。

| 確認方法 | 意味 |
|---|---|
| 自動 | 拡張機能を読み込んだ Edge で最初から最後までテスト |
| シミュレーター | 実際のコードを Claude API または AnkiConnect の模擬サーバーに対して完全に実行 |
| 模擬ページ | さらに、Netflix や YouTube と同じプレーヤー構造のページで実行 |
| 実セッション | YouTube で Chrome、実際のセッション、Claude API を使って手動で確認 |
| 未確認 | サイトの実際のセッションまたは自分の認証情報が必要 |

## 設計の方針

| 方針 | 適用 |
|---|---|
| 意味は文によって決まる | 「この文で」のブロックが文脈での意味を示し、比喩的または詩的な用法を指摘し、カードの最初に置かれます |
| 正しい読み方 | Claude が各行の読み方を確認し、手動でも修正できます |
| 広い文脈 | Claude は文の前後 40 行と翻訳を受け取ります。台本全体は修正時に送り、問い合わせでは任意です |
| 二重に払わない | 回答は単語と文ごと、確認済みの内容は行のテキストごとに保存します。中断した回答は最後まで受け取って保存し、同時に出た同じ問い合わせは 1 つのリクエストを共有します |
| 必要なときだけ Claude | パネルは辞書で開き、確認は動画全体ではなくこれから見る区間を対象にします |
| 見ている部分から | 翻訳、修正、確認は再生位置に従って区間を並べます |
| パソコンは使えるまま | 文字起こしは休み、使用状況に合わせ、失敗が続くと止まります |
| ちらつきなし | 丸ごと切り替わるもの（セクション、ビューアーのページ、辞書の語）は前のものを表示したまま準備し、一度に切り替える。時間がかかるときは細いバーで知らせる |
| メモリを抑える | 日本語の解析器は埋め草を除いた辞書をブラウザーで展開して読み込み、OCR は読み取りが止まるとモデルを解放し、Whisper は文字起こしの 3 分後に解放する |
| ページを書き換えない | ウェブの下線は内容に何も加えず CSS Custom Highlight API を使います。ふりがなが収まらない箇所の行間だけを広げます |
| データは手元に | すべてブラウザに残り、文字起こしの音声はパソコンの外に出ません |

## 既知の制限

| 制限 | 詳細 |
|---|---|
| 非常に大きな PDF | 開いている間、PDF はファイルと同じ大きさのメモリを確保する（pdf.js の仕組み）：550 MB のファイルはタスクマネージャーで 1 GB 以上と表示されるが、実際に使うのは読んだ部分だけ。閉じると解放される |
| 学習言語 | 日本語、英語、ドイツ語。新しい言語にはそれぞれ専用のパッケージが `src/lenguas` に必要です |
| 英語の分析 | 拡張機能に収まる小さなモデルが行います。あいまいな文では品詞を誤ることがあり、その場合は単語の下の訳も誤ります。単語パネルにはすべての定義が表示されます |
| ドイツ語の分析 | 辞書の語形から得ます。ドイツ語–英語の辞書がないと、各単語はそのままの形になります。2 つの候補の間は文を見ずに頻度で決め、Claude が行を確認するときに誤りを直します |
| ドイツ語の複合語 | 辞書にない複合名詞は部分に分けません |
| 英英辞書 | サイズが大きく、ダウンロードは約 110 MB、保存には約 220 MB 必要です。インストールと削除には数分かかります。表示言語が英語の場合にのみ提案します |
| 表示の翻訳 | AI の助けで書かれ、ネイティブによる確認はまだです。誤りは `idiomas/` で修正します |
| ページリーダー | メインフレームでのみ動作し、iframe の中のテキストには届きません。ページがキャンバスや画像に描いたものはテキストではありません |
| Claude のプロンプト | 他の言語での回答を求めるときも、指示はスペイン語のままです |
| プラットフォーム | デスクトップの Chrome と Edge。ローカルヘルパーは Windows 用です |
| DRM のある画像 | Netflix など保護されたサイトでは、ブラウザが渡す画面は黒くなります。サイトが提供すれば、カードにはエピソードの公式画像が入ります |
| DRM のある音声 | 保護されたサイトはキャプチャに音声を渡さないことがあります。1 つの動画で無音の文が 2 回続くと、録音のための再生し直しはしません |
| ビューアー | 文字認識は似た文字（エと工、ーと一）を取り違えたり、ときどき文字を落としたり、数式の添え字を失ったりすることがあります。元の画像は常に見えています。本モードは横書きで測定しています。DRM 付きの本は開けません。本のファイルは 1 ファイルのバックアップには含まれませんが、完全なコピーには含まれます。テキストの EPUB はページではなく章ごとにスクロールして読みます。漫画モードでは単語ではなく吹き出し全体をタップします。 |
| 同期 | サーバーなし：パソコン間の移行は完全なコピーで行います |
| 背景音楽 | 大きな音楽の下の小さな会話を Whisper が逃すことがあります |
| 曲の歌詞 | タイミングは単語単位ではなく Whisper の行単位です。音楽がとても大きいと Whisper がほとんど聞き取れないことがあり、その場合は推定のタイミングが増えます |
