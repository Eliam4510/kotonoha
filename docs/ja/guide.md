## はじめに

最初にようこそ画面が開き、言語、勉強する言語、レベルを尋ねて、辞書のインストール、Claude のキーの追加、カードの保存先の選択を提案します。スキップでき、**設定、外観**からもう一度見られます。その他はすべて、`Alt+Shift+K` で開く拡張機能のウィンドウの**設定**で変更します。

| 手順 | 場所 | 用途 |
|---|---|---|
| 辞書 | 設定、辞書 | スペイン語、英語またはドイツ語の JMdict、Kanjium のピッチアクセント、JPDB の頻度。一度ダウンロードするとブラウザに残ります |
| Claude の API キー | 設定、Claude | 説明、読み方の確認、翻訳、修正。ブラウザにのみ保存されます |
| その他の AI プロバイダー | 設定、その他の AI プロバイダー | 自分のキーで使う OpenRouter、DeepSeek、OpenAI、またはこのパソコンの LM Studio と Ollama を、選んだ作業に使う。Claude が引き続き標準 |
| 言語とレベル | 設定、言語とレベル | 表示言語と、それとは別に説明と翻訳の言語。レベルは説明の調整と、最初に表示するふりがなの量を決めます |
| 勉強する言語 | **ホーム**とサイドバー、設定、言語とレベル、拡張機能のメニュー、または動画上の**動画の設定、字幕** | 日本語、英語、またはドイツ語。言語ごとに単語、辞書、カード、設定を別々に保存します |
| Anki | 設定、カードと Anki | 任意。AnkiConnect アドオンを入れた Anki を開いておく必要があります |

拡張機能は Claude のキーがなくても動作します。字幕、辞書、ふりがな、色分け、カード、Whisper には不要です。

**その他の AI プロバイダー。** **設定**の「その他の AI プロバイダー」で、キーを入れて OpenRouter、DeepSeek、OpenAI を追加するか、キーなしでこのパソコンの LM Studio と Ollama を追加します。**モデルを見る**で各プロバイダーのモデルを一覧し、**接続をテスト**で最小限のリクエストを送ります。そのあと**作業ごとのモデルと努力レベル**で、作業ごとにそのモデルを使えます。構造のある回答は JSON スキーマ付きで頼み、DeepSeek のように対応していなければ、スキーマを指示に入れた JSON モードで頼みます。回答のトークンをそこまで許さなければ、少なめに頼みます。費用はプロバイダーが報告するコストで記録され（OpenRouter は報告します）、このパソコンのモデルはゼロと数えます。キーは Claude のキーと同じく別に保存され、ウェブページには届きません。指示は Claude に合わせて調整してあるので、ほかのモデルでは回答が悪くなることがあります。Ollama は `OLLAMA_ORIGINS=chrome-extension://*` を付けて起動したときだけ拡張機能に応答します。

### カスタマイズ

| オプション | 場所 | 用途 |
|---|---|---|
| ローマ字の読み方 | 設定、言語とレベル | まだかなを読めない人向けです。字幕、単語パネル、ページに適用されます |
| 単語の色 | 設定、外観 | 3 つのパレット：標準、赤と緑に頼らず区別できる色覚多様性向け、ハイコントラスト |
| ショートカット | 設定、キーボードショートカット | 動画の上のショートカットはここで変更します。音声キャプチャなどブラウザが使うものは、ブラウザのショートカットページで変更します |
| 費用の上限 | 設定、Claude | 上限に達すると、翌月まで Claude を使いません |
| リーダーを使わないサイト | 設定、ページリーダー、またはページ端のボタン | 邪魔になるサイトでだけオフにします |

## 動画の上の画面

日本語字幕のある動画を開くと、上部に浮動バーが現れます。推定理解度、おすすめの文、既知の単語、再生モードを表示します。自動で隠れ、マウスを上端で止めると再び現れ、マウスが近くにある間は表示され続けます。

**字幕。** 各単語には、ふりがな、ピッチアクセントによる色、状態による下線が付きます。状態は未知、追跡、既知、無視です。認識された文法ポイントはラベルで表示されます。

**字幕を動かす。** 単語の上も含めて、どこからでもドラッグして好きな高さと位置に動かせます。位置はすべての動画に適用され、動画の大きさに比例して保たれます。シアターモードでも同様です。背景をダブルクリックするか、表示設定の**元の位置に戻す**で元に戻ります。

**単語パネル。** 単語にマウスを合わせると、Claude へのリクエストなしで単語パネルが開きます。定義、頻度、音声、画像、例文、書き順に加え、Jisho、JapanDict、Weblio、Goo、Kotobank、Wiktionary、Forvo、Massif へのリンクがあります。JapanDict のリンクは同形語の一覧ではなく、JMdict の該当項目を開きます。

**この文で。** Claude のキーがあれば、**この文ではどういう意味ですか？**のボタンがその文脈での意味を示し、比喩的または詩的な用法を指摘します。Claude は文の前後 40 行と翻訳を受け取ります。**説明**、**分解**、**翻訳**のタブも同様で、押したときに尋ねます。回答はすべて保存されるので、その文のその単語に戻っても費用はかからず、パネルに**保存済み、費用なし**と表示されます。**深掘り**のボタンは Opus 5.5 で問い合わせ直します。

**画像で共有。** 単語パネルの頻度の横にある**画像で共有**ボタンは、単語とふりがな、アクセント、この文での意味（Claude に聞いていなければ辞書の意味）、単語を強調した元の文、動画や本のタイトルを載せたカードを描き、クリップボードにコピーします。チャットに Ctrl+V で貼り付けるだけです。**この文の文法**の各項目にも同じボタンがあり、文型、レベル、意味、Claude の説明の最初の項目を載せたカードになります。カードはテーマと同じく**墨**と**紙**の 2 種類で、最後に選んだスタイルを覚えています。**画像を保存**で PNG としてダウンロードできます。カードはブラウザーの中で描かれ、何も送信しません。

**書き順。** 単語パネルの**書き順**タブは、単語の各漢字の書き方を示します。画が番号付きで 1 画ずつ描かれ、繰り返します。一時停止、1 画ずつの移動、速度の変更ができます。データは [KanjiVG](https://kanjivg.tagaini.net) のもので、各漢字は最初に一度ダウンロードされ、ブラウザに保存されます。その下の**この漢字を使う、もう知っている単語**には、漢字ごとに、その漢字を含み、既知または学習中にした単語が並びます（冷蔵庫：冷たい、車庫、金庫）。既知のものが先です。知っている単語から新しい漢字を覚えられます。

**字幕ナビ。** `G` で、すべての行、フィルター、印、複数選択を備えたサイドパネルが開きます。行の結合、複数カードの作成、同期もできます。

**再生モード。**

| モード | 動作 |
|---|---|
| 標準 | 止まらず、字幕も隠さずに再生します |
| 準備リスニング | 各文の前で止まり、翻訳を表示します |
| 精読 | 各文の前で止まり、読んでから聞けるようにします |
| 集中リスニング | 文が話されるまで字幕を隠し、その後止まって表示します |
| ディクテーション | 字幕を隠して各文の終わりで一時停止し、聞こえた内容を書いてもらって、合っていた部分を示す |
| 集中ハイブリッド | 各文の後で、字幕を表示したまま止まります |
| 一時停止時に表示 | 動画の一時停止中だけ字幕を表示します |
| 1D フォーカス | 未知語が 1 つだけの文で止まります |
| カスタム | 停止と隠し方を調整できます |

**ディクテーションと自分の声でリピート。** **ディクテーション**モードでは、各文の終わりで動画が止まり、字幕の位置に聞こえた内容を書きます。**確認**を押すと、合っていた言葉は緑、半分なら黄色、聞き逃した言葉は下線で示され、点数が表示されます。日本語は読みで比べるので、かなで書いても構いません。漢字の言葉に、書いた内容と合う別の辞書の読み（後をあと）があれば正解になります。**もう一度聞く**で文を繰り返し、**続ける**か Enter で先に進みます。結果の**自分の声でリピート**か、字幕の上で `P` キーを押すと、Kotonoha のウィンドウでその文のアクセント練習が開きます。動画で `S` を押して聞き、同じように言って、イントネーションを比べます。

セリフのない場面は、動画パネルから早送りやスキップができます。

## 字幕

### トラックを選ぶ

**動画と字幕**パネルの**字幕**タブで、日本語のトラックと第2字幕を選びます。既定では、人が作った字幕を自動字幕より優先し、読み込んだ字幕を何よりも優先します。

### Claude で翻訳

**AI 字幕**パネルの翻訳ボタン、または第2字幕の横の **Claude で翻訳**は、日本語字幕を補助言語に翻訳します。スペイン語、英語、ポルトガル語、フランス語、ドイツ語に対応します。

- 今見ている部分から始めるので、その部分は数秒で用意できます。
- 結果は届いた順に表示されます。
- キャンセルしても翻訳済みの部分は残り、もう一度押すと足りない行だけを要求します。

### 自動字幕を修正する

自動字幕はよく同音異義語を間違えます。Claude はタイトルと全文を文脈にして、確認なしで修正します。

- 自動トラックでは既定でオンで、パネルでオフにできます。
- 明らかな誤りがある部分だけを変更します。認識が作り出したと Claude が判断した行は削除されます。
- 修正は保存され、再度要求されません。
- ナビには修正された行に印が付き、元の文を確認できます。

### 他の言語から日本語を作る

他の言語の字幕しかないときは、Claude が日本語に直せます。翻訳の翻訳なので、聞こえる内容と完全には一致しません。日本語の字幕ファイルがあれば、常にそちらが優れています。

### 読み込みと書き出し

各トラックには**読み込む**と **SRT を書き出す**のボタンがあります。ファイルを動画の上にドラッグすることもできます。SRT、VTT、ASS、SSA、TTML、DFXP に対応します。

- 読み込んだ字幕はそのタイトルに保存され、サイトのトラックより優先されます。
- 書き出しには同期の調整が含まれます。

### Netflix の地域

Netflix の作品の日本語字幕は、視聴時に作品の識別子とともに保存されます。他の地域のカタログに同じ作品がそのトラックなしで提供されている場合、Kotonoha はそれを「日本語（保存済み）」として表示し、その地域で提供されるものを第2字幕にします。SRT に書き出してファイルを読み込めば、同じことを手動でできます。

### 同期

**同期**タブで各トラックのずれを調整します。ナビの**同期：この行が今流れています**も使えます。印 1 つでずれを、2 つで速度も修正します。ずれは `Alt+I` と `Alt+O` で調整できます。

## Whisper による文字起こし

Whisper は、字幕のない動画の日本語字幕を作ります。WebGPU でグラフィックカード上で動き、音声はパソコンの外に出ません。最初にモデルをダウンロードし、ブラウザに保存します。Netflix では提供しません。作品のほとんどに字幕があるためです。

| ソース | 必要なもの | 速度 |
|---|---|---|
| 手元のファイル、アプリのプレーヤーで | なし | 動画 30 分あたり約 5 分 |
| ネット動画、ローカルヘルパーあり | ヘルパーのインストール | 動画 30 分あたり約 5 分、加えてダウンロード時間 |
| ネット動画、ヘルパーなし | `Alt+Shift+M` または拡張機能のメニューのスイッチで音声キャプチャをオン | 実時間、数秒の遅れ |

**モデル。**

| モデル | ダウンロード | 用途 |
|---|---|---|
| 自動 | | 既定。日本語の話し声には Haas-ja、英語とドイツ語の話し声には Parakeet、歌には Whisper Turbo |
| Haas-ja | 1.3 GB | 日本語のみ。話し声に最も正確で速く、BGM があっても同様で、句読点も付く |
| Parakeet | 1.3 GB | 英語とドイツ語。話し声に最も正確で速く、BGM があっても同様で、句読点と最も正確なタイミングが付く |
| Whisper Turbo | 1.5 GB | 歌に最適 |
| Whisper Turbo 軽量版 | 564 MB | 精度はやや低く、ビデオメモリは少なめ |
| Whisper Base | 165 MB | 高性能な GPU のないパソコン向け |

自動では、歌詞を貼り付けたとき、サイトが音楽に分類しているとき、またはタイトルに「MV」や「歌ってみた」などとあるときに、歌として扱います。日本語の話し声では、Haas-ja の誤り率は 3% で、Whisper Turbo の 9% を下回り、30 分を約 1 分で文字起こしします。Whisper では約 5 分かかります。歌では歌われた内容の一部しか書かないため、Whisper Turbo のほうが向いています。英語では Parakeet が同じ役割を担い、誤り率は 6.8% で Whisper Turbo の 9.6% を下回り、タイミングは 3 倍正確です。文字起こしの間、パネルにどのモデルが動いているかが表示されます。

モデルはブラウザに保存され、再ダウンロードはしません。毎回ディスクから読み込むため、数秒かかることがあります。**設定、音声の文字起こし、保存済みのモデル**で、それぞれの使用容量を確認して削除できます。拡張機能をアンインストールしても削除されます。

**強度。** グラフィックカードが働く時間の割合を決めます。残りの時間は休み、他のアプリがカードを使っていると休みは自動で長くなります。

| 強度 | 占有率 | 動画 30 分 |
|---|---|---|
| 自動 | パソコンの使用中は 75%、未使用が 2 分続くと 90% | 約 5 分 |
| 控えめ | 30% | 約 12 分 |
| 速い | 90% | 約 4 分 |

文字起こし中は一時停止してカードをすぐに解放し、同じ位置から再開できます。グラフィックドライバーが再起動すると、Whisper は 20 秒待ち、モデルを読み込み直して最低の強度で続けます。2 回目の失敗で止まり、文字起こしした分は保存されます。

### 曲の歌詞

Whisper はタイミングは正確ですが、曲では多くの言葉を聞き間違えます。動画のコメントなどに歌詞が公開されていれば、**AI 字幕**パネルの**曲の歌詞**に貼り付けると、Claude がそのタイミングに配置します。

- Claude が示すのは、どのフレーズが文字起こしのどの行で聞こえるかだけです。言葉は歌詞のまま、タイミングは Whisper のものです。
- 文字起こしの前か途中で歌詞を貼り付けると、終わったときに自動で調整され、Whisper が聞いた内容の修正や確認に費用はかかりません。動画にすでに字幕トラックがあれば、**歌詞をこのタイミングに合わせる**でそれを基準にすることもできます。
- 一度しか書かれていないサビは、歌われるすべての箇所に配置します。セクションの印、ローマ字、翻訳など、歌われないものは無視します。
- Whisper が聞き取れなかったフレーズには推定のタイミングが付き、最後の通知にその数が示されます。その場合は、ナビゲーターの**同期：この行が今流れています**で微調整できます。
- 結果は、その動画に保存されるもう 1 つのトラック「日本語 (歌詞)」です。元の文字起こしも残ります。1 曲につき Claude へのリクエストは 1 回で、同じ歌詞で調整し直しても費用はかかりません。
- ローカルヘルパーなしのネット動画では、Whisper が曲全体を聞く必要があります。動画が終わると文字起こしは自動で止まり、歌詞が調整されます。

### ローカルヘルパー

拡張機能だけでは動画の音声をダウンロードできません。ヘルパーは Windows に最初から入っている PowerShell で書かれた小さなローカルプログラムで、Python も FFmpeg もインストールする必要はありません。[yt-dlp](https://github.com/yt-dlp/yt-dlp) で音声をダウンロードし、拡張機能の更新も行います（[データとバックアップ](#データとバックアップ)の**新しいバージョン**を参照）。最新バージョンのページから `kotonoha-X.Y.Z-ayudante.zip` をダウンロードして任意のフォルダーに展開し、`Instalar.cmd` をダブルクリックします。インストーラーは次のことを行います。

- ヘルパーを `%LOCALAPPDATA%\Kotonoha\ayudante` にコピーします。展開したフォルダーはその後は不要です。
- yt-dlp と、yt-dlp が YouTube の確認を解くのに使う QuickJS を、それぞれの GitHub の公式ページからダウンロードし、SHA-256 を確認します。
- Chrome、Edge、Brave、Chromium で Kotonoha を探し、見つけたコピーごとにヘルパーを登録します。
- 1 つも見つからなければ、拡張機能も固定の識別子でインストールするよう提案し、読み込み方を説明します。

状態は**設定、文字起こし**で確認できます。インストーラーがコピーを見つけられない場合は、設定にその識別子入りのコマンドが表示されるので、ヘルパーのフォルダーで実行します。

```bash
powershell -ExecutionPolicy Bypass -File instalar.ps1 -Extension EXTENSION_ID
```

| 項目 | 動作 |
|---|---|
| 範囲 | 拡張機能だけが呼び出せ、http または https のアドレスだけを受け付けます |
| 登録 | 管理者権限なしで `HKCU` にユーザーごとのキーを追加します |
| 変換 | パソコンに FFmpeg があればヘルパーが音声を変換します。なければ拡張機能が自分の FFmpeg で変換し、少し時間がかかります |
| yt-dlp | 週に 1 回、自動で最新になります。YouTube はよく変わるためです |
| ファイル | 終了時またはキャンセル時に削除される一時フォルダを使います |
| アンインストール | `Desinstalar.cmd` をダブルクリックします。拡張機能とそのデータには触れません |

非公開や年齢制限などで動画をダウンロードできない場合、通知が再生しながらの文字起こしを提案します。

## カード

| ショートカット | 操作 |
|---|---|
| `Q`、`Alt+Q` | 現在の単語と文でカードを作成します |
| `E` | マウスの下の単語、選択範囲、画像をカード作成に送ります |

カードは AnkiConnect で Anki に送る（自分のノートタイプか拡張機能が作るものを使う）か、FSRS を使う内蔵の復習である**メモリー**に保存できます。フィールドは文、ふりがな、翻訳、定義、音声、画像、メモです。音声キャプチャは `Alt+Shift+M` または拡張機能のメニューのスイッチでオンにします。

**動画の音声と画像。** 文の音声を録音するには、動画のタブで `Alt+Shift+M` または拡張機能のメニューのスイッチでキャプチャをオンにします。キャプチャはそのタブだけです。別のタブでオンになっていると、マイクのアイコンがオフで表示され、カードは音声なしで作られます。カードを作るとき、その行を通常の速度で再生し直して録音し、動画は元の位置に戻ります。画像には画面の要素は一切入りません。Netflix のように DRM のあるサイトでは、ブラウザが渡す画面は黒くなります。その場合カードにはエピソードの公式画像が入り、サイトになければ画像なしです。保護されたサイトは音声も渡さないことがあります。カードは音声なしで作られ、1 つの動画で無音の文が 2 回続くと、録音のための再生し直しはしなくなります。

## ウェブページ、リーダー、ライブラリ

**ウェブページ。** 日本語のあるページでは、リーダーが単語に知っている度合いに応じて下線を引き、ふりがなを付けます。単語をクリックすると単語パネルが開きます。リンクとボタンではクリックはサイトのままで、マウスを合わせるとパネルが開き、`Shift` ですぐに開きます。ドラッグはそのままテキストを選択し、パネルが開いているときは `1`〜`4` と `Q` が使えます。

右端のボタンでページを離れずに色分けとふりがなを調整でき、拡張機能のメニューでリーダーをオンオフします。ふりがなには 4 つのモードがあります。すべての単語、新しい単語だけ、マウスを合わせたとき、表示しない、です。**設定、ページリーダー**で、パネルを常にマウスを合わせたときに開くようにしたり、リンクのクリックでも調べるようにしたりできます。

これらはページの内容に何も加えません。色分けは CSS Custom Highlight API を使い、読み方は別のレイヤーにあるので、選択、コピー、検索はそのままで、React などで作られたアプリの邪魔もしません。チャットの会話のようにボックスの中でスクロールするものにも対応し、ふりがなは文字と一緒に動いて入力欄の下を通ります。入力欄、中国語や韓国語のテキストには作用しません。

**行間を広げる。** 行の間が狭いページは多く、ふりがなが上の行とぶつかってしまいます。そこではそのテキストの行間を必要なだけ広げます。リーダーがページで動かすのはこれだけです。ボタンやメニューでは行わず、テキストが高さ固定のボックスからはみ出す場所でも行いません。そうした場所にまったく余裕がなければ、ふりがなはマウスを合わせるまで表示しません。端のボタンの**行間を広げる**スイッチでオフにでき、その場合レイアウトはまったく動きません。

`Alt+K`、`Alt+U`、`Alt+I` は、選択したテキストをまとめて既知、未知、無視にします。

**ノート。** 以前のクリップボードです。画面の幅いっぱいのページに書式付きの文章を書いたり貼り付けたりでき、字幕と同じ補助を使って読めます。上部の**編集**と**読む**で、同じページのままモードを切り替えます。編集中は、ブロックの種類で**本文**、**大見出し**、**中見出し**、**小見出し**、**コード**を選び、ボタンで**箇条書き**、**番号付きリスト**、**引用**、**太字**を付けます。いつものショートカットも使えます。行頭に `# ` で見出し、`- `（日本語では ・ も）で箇条書き、`1. ` で番号付きリスト、`> ` で引用、Tab で下位項目、Ctrl+B で太字です。ページから貼り付けた内容は構造を保ち、そのページのふりがなは入りません。Claude のチャットからコピーした Markdown も書式付きで入ります。**整理**は、ひと続きで貼り付けた文章に、言葉を変えずに見出し、小見出し、段落、箇条書きを付けるよう Claude に頼みます。言葉が変わった場合は知らせ、Ctrl+Z で元に戻ります。書いた内容はブラウザーに自動で保存されます。**ライブラリに保存**でライブラリに移り、それ以降はそこにも保存されます。**新しいノート**は前のノートを失わずに白紙のノートを始めます。前のノートがライブラリになければ、ライブラリに入ります。ライブラリの文章は**ノートで編集**でもう一度編集できます。すべて Markdown で保存されるので、テキストのままで、ライブラリやバックアップでも同じように読めます。

**Web モード。** アプリのウィンドウにはタブがないため、ブラウザーの分割表示に入れません。ノートの **Web モード**ボタンはサイドバーなしの通常のタブでノートを開き、拡張機能のメニューの**このタブの横にノートを開く**は、見ているページのすぐ横にノートを置きます（Chrome 155 以降）。そのタブでは、タブが見えている間、**クリップボードを追う**がどこでコピーした学習中の言語の文章も末尾に足します。どのページでも、選択した文章のメニューの**選択した部分をノートで開く**も末尾に足します。拡張機能自身のページなので、サーバーは不要で、オフラインでも動き、文章はパソコンの外に出ません。

**音声入力。** ノートの**音声入力**はマイクで録音し、話した内容を末尾に独立した段落として足し、解析済みでふりがな付きで表示します。録音中は時間とマイクの音量が表示され、**終了**で録音を終え、**キャンセル**で破棄します。文字起こしは**設定**の「音声の文字起こし」で選んだモデルでパソコン上で行います。自動では、日本語は Haas-ja、英語とドイツ語は Parakeet です。話している間にモデルを読み込むので、録音を終えてから文字起こしまでは数秒です。録音も文章もパソコンの外に出ません。段落の上には聞き返せるように録音が残り、ライブラリに保存するときも文章と一緒に入ります。編集中、録音は「音声入力の録音」ブロックです。消すと段落は残り、録音は録音から 1 週間後に削除されます。最初はブラウザーがマイクの使用許可を求めます。1 回の録音は最長 10 分です。

**読み上げ。** ノート、ライブラリの文章、ビューアーのテキスト表示では、下のバーの**読み上げ**が文の音声（ローカル、ニューラル、Azure、ブラウザーの音声）で一文ずつ読み上げます。速さのボタンは 0.6×、0.8×、1×、1.2× を順に切り替え、モードのボタンは**続けて**、一文ごとに止まる**一文ずつ**、一緒に言えるよう同じ文を少し間を置いて繰り返す**繰り返す**を順に切り替えます。どちらも記憶されます。マウスで文章の好きな部分を選択すると、そこを読み上げる**聞く**と、日本語ではその部分でアクセントの練習を開く**練習**が出ます。一語でも、文の途中でも、数文でもかまいません。

**アクセントの練習。** ノート、ライブラリのテキスト、ビューアーのテキスト表示では、下のバーの**練習**で今の文の練習を開きます。**前の文**と**次の文**で別の文に移ります。各単語の上にはアクセントが描かれます。モーラごとに高いか低いかを示す線で、アクセント核の後で下がります。**文を聞く**は、キーがあれば Azure の音声で、なければブラウザーの音声で読み上げます。**録音**は、声に出して読んだ文を最長 20 秒録音します。Kotonoha は録音の音の高さをブラウザーの中で測り、パソコン上で Haas-ja によって文字起こしして、各単語がどこで発音されたかを調べます。グラフは声の高さの曲線をお手本のアクセントに重ねて表示し、単語ごとに判定が付きます。**良い**は正しい位置で下がった場合、**要確認**は別の位置で下がったか下がらなかった場合で、どこで下がるはずだったか、どこで下がったかを示します。**判定なし**はアクセントがわからない活用形、**認識できず**は録音にその単語が見つからない場合です。文の途中の単語の間の長いポーズも示します。**自分の録音を聞く**で録音を再生し、**もう一度録音**でやり直します。判定するのは音の下がる位置で、これがアクセントを区別します。最初の上昇は続けて話すと現れないことがあるため数えず、ポーズの前の最後のモーラも文のイントネーションを担うため数えません。各単語のアクセントは「ピッチアクセント（Kanjium）」辞書から取ります。この辞書がない場合は、核が動詞によらない〜ますの丁寧形だけを判定します。あくまで目安です。読み上げた文では、自動の測定がいつも正しいとは限りません。録音もテキストもパソコンの外には出ず、録音は保存されません。音声モデルは練習を開いたときに読み込まれ、開いている間は読み込まれたままです。最初の録音は読み込みが終わるまで待ち（開発用のパソコンで約 30 秒）、2 回目からは 1 秒もかからずに分析します。

**特殊拍。** 練習パネルで**「っ」「ん」と長音も確認する**をオンにすると、Kotonoha は録音の中で特殊拍が抜けていないか、余分に入っていないかも確認します。聞こえない「っ」（きって を きて と言う）、「ん」（かんじ を かじ と言う）、短く言った長音（おばあさん を おばさん と言う）、または余分な拍（おばさん を おばあさん と言う）です。**モーラ**のラベルが付いた各指摘はどの単語かを示し、お手本のアクセントでそのモーラに印を付けます。指摘がなければ、**モーラ**が抜けも余分もないことを伝えます。聞き取るのは、パソコン上で動く日本語の音素モデル narabas です。GPU がプロセッサーと同じ結果を出せば GPU で、そうでなければプロセッサーで動きます。最初に作者の GitHub の公開ページから 1.26 GB をダウンロードし、SHA-256 で確認してブラウザに保存します。**設定、音声の文字起こし**の**保存済みのモデル**で削除できます。s、sh、z、j、h、f の前の「っ」はモデルが示さないため判定せず、違う言い方をした句や認識されなかった句も判定しません。単語の終わりで伸ばした母音や間も数えません。言いよどみであって、単語の誤りではないからです。2 つの合成音声で読んだ最小対で測ったところ、抜けた拍 22 個のうち 17 個、余分な拍 10 個のうち 10 個を見つけ、正しく言った文 24 個のうち 22 個では何も指摘しませんでした。

**ローカル音声。** パソコンで AivisSpeech か VOICEVOX を起動していると、Kotonoha は日本語の文をそれで読み上げます。読み上げ、練習の**文を聞く**、単語カード、カード用の音声に使われます。**設定**の「音声」にある**ローカル音声**は、いつものポート（AivisSpeech は 10101、VOICEVOX は 50021）で見つかったかを示し、**ローカル音声で文を読む**でオンにして、**音声とスタイル**を選びます。**辞書のアクセント**をオンにすると、読み上げる前にアクセント辞書で各単語のアクセントを直すので、お手本の音声は辞書のとおりに話します。音声はキャッシュされ、一度読んだ文はすぐに再生されます。プログラムが閉じていれば、キーがあれば Azure で、なければブラウザーの音声で読み上げます。AivisSpeech は無料で、何もパソコンの外に出ません。

**ライブラリ。** ビューアーで開く EPUB・CBZ・PDF の本や画像フォルダーと、テキスト、SRT 字幕を、読書位置と各章の構成とともに保存します。設定したレベルに合わせた物語を Claude で作ることもできます。

**ビューアー。** 漫画やスキャンした本のような画像の EPUB、CBZ、PDF は、PDF リーダーのように専用のタブのビューアーで開きます。ズーム（**拡大**、**縮小**、**幅に合わせる**、**ページ全体**。Ctrl とマウスホイールでも可能）、三つの表示（**単ページ**、**見開き**、**連続スクロール**）、**サムネイル**、本の**目次**、**全画面**があります。漫画のように右から左へ読むと宣言している本はその向きで表示され、左矢印で先へ進み、見開きでは表紙を単独にして印刷版と同じページの組み合わせにできます。矢印キー、Home、End でページをめくり、F で全画面になります。ファイルはブラウザの保存領域にそのまま保存されて少しずつ読み込まれ、全体を一度に読み込むことはありません。ビューアーは本ごとにページ、表示、ズームを覚えています。

**画像フォルダー。** 画像で届いた漫画は、**画像フォルダーを選択**を押すか、フォルダーをドラッグして読み込みます。画像のあるフォルダーはそれぞれ1冊の本になります。巻らしいサブフォルダーだけを含む場合、つまり名前（「第01巻」「Vol. 2」「v03」）や、200枚ほどの画像を含むことから巻と判断できる場合は、巻ごとに別の本になり、名前が番号だけならシリーズ名が前に付きます。章らしいサブフォルダーなら、1冊の本の目次になります。ページは自然な順序に並び、「cover.jpg」という名前でも表紙が先頭に来ます。画像以外のファイルは無視され、ComicInfo.xml があればタイトルと読む向きを使います。各本は CBZ として保存され、画像を再圧縮したりメモリにコピーしたりしません。**見開き**では、横長のページ（一枚でスキャンされた見開き）は単独で表示されます。

**コレクションと読書の進み具合。** 本は、シリーズとその各巻、あるテーマの本などのコレクションにまとめられます。複数の巻が入ったフォルダーは、その名前のコレクションとしてそのまま読み込まれ、同じフォルダーから読み込んだ新しい巻もそこに加わります。**新しいコレクション**では、名前、種類（**漫画**、**小説**、**学習**、**その他**）、説明を付けて手動で作れます。コレクションの中では、**本を追加**で本棚の本を加え、**ここに読み込む**でファイルを直接読み込み、**表紙**で収録された本の表紙か自分の画像を選びます。**コレクションを解除**しても、中の本は本棚に残ります。各本にはどこまで読んだかが表示され、最後のページまで読むと**読了**になります。本のメニューからは、別のコレクションへの移動、表紙の変更、読了にする、最初から読み直す、ができます。本棚の上の**続きを読む**から読みかけの本にすぐ戻れ、**読書中**・**未読**・**読了**の絞り込みで、コレクションの中の本も含めてそれぞれを表示できます。PDF は読み込んだ時点で表紙とページ数が分かり、ビューアーの**このページを表紙にする**で好きなページを表紙にできます。

**ページの文字。** **ページの文字を読み取る**ボタンは、画像のページの文字を自分のパソコンで GPU を使って認識し、ページの上に重ねます。マウスを合わせると行ごとに示され、タップすると横に開き、ふりがなと調べられる単語、単語パネルとカード作成が使えます。モードは二つあります。**本**は印刷された本やスキャンした PDF 向け、**漫画**は吹き出しと縦書き向けで、ふりがなを本文と取り違えません。**本**では印刷されたふりがなが本文に混ざらず、2 段組のページは段ごとに読みます。**漫画**では吹き出しがコマの順に並び、透かしやページ番号は除かれます。右から左へ読む本は**漫画**モードで始まります。すでに文字を含む PDF ではその文字を使います。それが別の文字認識ソフトによる誤りの多い文字なら、**PDFの文字**をオフにすると、Kotonoha がそのページも読み取ります。スキャンした PDF では、画面に描いたページではなく、スキャン画像をそのままの解像度で読み取るので、誤りがずっと少なくなります。初回はモデルをダウンロードし（本は 25 MB、漫画は 178 MB）、各ページは一度だけ、1〜2 秒で読み取ります。文字認識は似た文字を取り違えたり、数式の添え字を落としたりすることがありますが、元の画像はそのまま見えます。次のページはたどり着く前に読み取っておくので、ページをめくるともう文字があります。ある行で文字を取り違えていたら、行パネルの**編集**で文字を手で書き換えられます。編集した内容は別に保存され、ページを読み取り直しても失われず、**復元**で読み取った文字に戻ります。ライブラリの各本のカードでは、**処理する**で全ページを一度に文字認識で読み取り、進み具合を表示します。一時停止して後で続けても何も失われず、終わると本に**文字の準備完了**と表示され、文字認識がオンになります。

**メモとしおり。** ページの本では、**このページにしおりを挟む**でページにしおりのひもが掛かり、サムネイルにも表示されます。行パネルでは、**ハイライト**で行を 4 色のどれかで塗り、**下線**で下線を引きます。単語を選ぶか、ドラッグして範囲を選ぶと、その部分だけに付けられます。ハイライトには**コメントする**でコメントを添えられます。**メモを追加**では、タップしたページ上の位置にメモを貼れます。開いて読んだり書き直したりできる付箋です。**メモとしおり**パネルはすべてをページ順にまとめ、各項目への移動、編集、削除ができ、**コピー**でテキストとしてクリップボードに入れられます。ハイライトはページの画像上に保存されるので、文字認識がページを読み直しても位置はそのままで、すべてバックアップに含まれます。

**本の中を検索。** **本の中を検索**（または Ctrl+F）は、文字のあるすべてのページから単語を探します。PDF に含まれる文字と文字認識で読み取った文字が対象で、編集した内容が優先されます。大文字と小文字、全角と半角、ひらがなとカタカナは区別せず、日本語では 2 行にまたがって分かれた単語も見つかります。結果はページごとに前後の短い文と一緒に表示され、Enter で次へ、Shift+Enter で前へ移動し、見つかった箇所はページ上に示されます。文字認識がまだ読み取っていないページは検索されません。パネルにそのページ数が表示され、**処理する**でまとめて読み取れます。

**テキスト表示。** **テキストで表示**は、ページの画像の代わりにその文字を表示します。行は段落にまとめられ、見出しは分けて表示され、ノートの読書支援が付きます。ふりがな、色分け、理解度、**読み上げ**、カードを作れる単語パネルです。漫画では吹き出しひとつがひとつの段落になります。ページは画像と同じようにめくれ、**ページを表示**で画像に戻ります。本ごとに最後に使った表示を覚えています。

**Claude で確認。** **Claude で文字を確認**は、ページの画像と読み取った文字を Claude に送り、Claude は画像と一致しない行だけを提案します。変更は 1 文字ずつ示され、どれを適用するか選べます。**適用**を押すまで何も変わりません。確認した行のパネルには「Claude で確認済み」と表示され、**復元**で元に戻せます。Claude のキーが必要です。この作業には Claude Haiku 5.5 を使い、費用は 1 ページあたり 1 米セント未満です。モデルは**設定**の「ページの文字の確認」で変更できます。同じ文字のまま同じページをもう一度確認しても、料金は再びかかりません。確認するページはほかのリクエストと同じように Claude に送られますが、本のほかの部分がコンピューターの外に出ることはありません。

**テキストの本。** 小説のようなテキストの EPUB は、章、CSS、ルビ、挿絵、縦書きなど元のレイアウトのままビューアーで開きます。その上にページリーダーが重なり、ウェブと同じように色分けとふりがなが付き、単語をクリックすると単語パネルが開きます。矢印キー、Page Up、Page Down、マウスホイールでページをめくり、縦書きの本では左へ進み、章の終わりでは次の章に移ります。**目次**から各章へ移動でき、本の中のリンクも使えます。**拡大**と**縮小**で文字の大きさを変え、**縦書き**をオフにすると縦書きの本を横書きで読めます。ビューアーは章と正確な位置を覚えています。本の中身が実行されたり、インターネットから何かを読み込んだりすることはありません。

**テキストを含む PDF。** PDF に文字が含まれていれば、OCR もダウンロードもなしにそのまま使います。行をタップするだけです。テキストを含む PDF や**本**モードで読み取ったページで単語をタップすると、単語パネルが直接開き、その単語がページ上で示されます。

**ローカルプレーヤー。** ffmpeg.wasm で MKV の内蔵字幕と音声トラックの選択に対応し、手元のファイルを再生します。

**単語と評価。** 単語一覧は語彙を状態別に並べ、レベル評価は最初の既知語数を推定します。

**JLPT。** サイドバーの **JLPT** には、N5 から N1 までの各レベルの語彙・漢字・文法と、そのうちすでに知っているものがまとまっています。レベルごとのカードは知っている単語と漢字の数を数え、リングで語彙のどれだけを知っているかを示します。**語彙**では各単語に状態が付き、その行で 1 語ずつ、またはまとめて変えられます。**リストの … 件をすべて選択**して状態を選ぶと、たとえばもう知っている N5 の単語を一度に登録できます。**漢字**では、知っている単語に含まれていればその漢字を知っているものとします。押すと読み、意味、書き順、その漢字を含むレベル内の単語が表示されます。**文法**では各項目に意味が付き、開くとこれまでに見た動画やページ、本の中でその項目が出てきた文が、文型を強調して表示されます。**Claude で説明**は例文付きで説明します。JLPT に公式のリストはありません。語彙と漢字は広く使われている Jonathan Waller のリスト（CC BY）、文法は約 500 項目の独自リストです。

**辞書。** 辞書ページはウィンドウの幅をすべて使います。左に検索結果の一覧、中央に選んだ単語、右にその単語の関連情報が並びます。幅が狭いと、一覧は横にスクロールする一列になり、右の段は下に移ります。さらに狭いウィンドウでは、すべてが一段にまとまります。かなで検索すると、その読みの単語を別々に表示し（のむ → 飲む、呑む）、漢字で検索すると、それで始まる単語も表示します（日本 → 日本語、日本人）。各語義は訳語をまとめて表示し、その上に品詞と用法（五段動詞、他動詞、口語）を辞書ごとに示します。ページはタブを開かない状態で表示され、音声、画像、Claude はそれぞれのボタンで呼び出します。右には、その漢字（JLPT のレベル、読み、意味）、英語版 JMdict にもとづく**対義語**（上手なら下手）と**参照**、意味が同じよく使われる言葉の**同じ意味**（食べるなら食う、召し上がる）、**同じ読みの言葉**（橋なら箸と端）、Claude に聞く**似た言葉とその違い**があります。一覧はすべてカードで、読みは単語の上、意味は下に表示され、よく使われる言葉には星、知っている語や学習中の語には点が付きます。

**見かけた場所。** 単語の下には、その単語が出てきた動画や文章の文が、読みを上に付け、活用していても単語を強調して表示されます。文の中の別の単語を押すと、その単語を引きます。動画の文には聞こえた時刻と**12:34 に戻る**があり、動画のタブが開いていればそこへ、なければ開いて、その時刻に移動します。動画の上の単語パネルの**例**タブにも同じボタンがあります。

**漢字一字。** 漢字一字（たとえば愛）を検索すると、その漢字のページが開きます。大きく一画ずつ示す書き順、意味、JLPT のレベル、画数、読み（音読みと訓読み）、KanjiVG にもとづく**構成要素**（部首と音符を示し、それぞれに専用ページがあります）、知っている語や学習中の語の**「愛」を含むあなたの単語**、その漢字を含むよく使われる言葉の**「愛」を含む単語**（よく使われる順）、漢字の読みどおりに読まないよく使われる言葉の**「愛」を含む特別な読み**（可愛いなど。「今」なら今日と今朝）、対義語（あれば）、見かけた場所、ゴシック体・明朝体・手書きで見る**字形**、Claude に聞く**成り立ちと覚え方**があります。その漢字が単語でもある場合は、上の**単語**で単語として表示できます。

**漢字辞典。** **漢字（Kanjium・KANJIDIC）**辞典をインストールすると、漢字のページの情報がぐっと増えます。ページ上の**インストール**か、**設定、辞書**からインストールできます。約 3 MB で、6812 字を収録しています。意味は英語で表示され、インターフェースがスペイン語のときは約 2500 字がスペイン語で表示されます。漢字の横には、属している漢字表（日本で習う学年つきの**常用漢字**、人名に使える**人名用漢字**、または表外漢字）、**漢検**の級、使用頻度の順位が表示されます。読みは分けて表示されます。まず表内の読み、**その他**の下に表外の読みが並び、**名乗り**には人名にだけ使われる読みがまとまります。音読みにはそれぞれ伝わった時代（**呉音**、**漢音**、**唐音**）が示され、表内でもほとんど使われない読みは点線の枠で表示されます。その下には、授業で使う呼び名（さんずい）と番号のついた**部首**と、**成り立ち**（象形文字、指事文字、会意文字、形声文字）があります。さらに下の**この字を音符とする漢字**と**同じ音符を持つ漢字**には、同じ音符を持つ漢字がまとまります（「青」を持つ晴、清、精など）。**この字を含む漢字**はそれ以外の漢字、**形の似た漢字**は読むときに混同しやすい漢字です。**対義の漢字**と**意味の似た漢字**、アクセントで区別できるかどうかも示す**同訓異字**（「かみ」と読む神、紙、髪など）、**旧字体・異体字**（「国」の旧字体「國」など）もあります。旧字体のページでは、現在の字体が案内されます。データは Uros O. 氏の [Kanjium](https://github.com/mifunetoshiro/kanjium) と EDRDG の KANJIDIC によるものです。

**書く練習。** 漢字のページで**練習**を選ぶと、書き順の代わりに、マウス、ペン、指で書けるマスが表示されます。**なぞり書き**では漢字が薄く表示され、点が次の画の書き始めを示します。**何も見ずに**では、マスは空のままです。一画ごとに、離したときに判定されます。正しければその場に残り、違っていれば消えて理由が表示されます（向きが逆、まだ順番ではない別の画、形が違う）。同じ画を二度間違えるか、**ヒント**を押すと、その画が自動で描かれます。最後の一画の取り消しや全消去ができ、書き終えると復習したほうがよい画が示されます。

**意味と分類で探す。** 「dog」のように英語やスペイン語で書くと、その意味を持つよく使われる日本語の言葉が表示されます。検索した言葉は JLPT の文法とも照らし合わされ、形（わけ）や意味（「although」）で探せます。各項目を開くと例文と説明が表示されます。トップの**辞書を探検する**には、JMdict のタグにもとづいて、オノマトペ、特別な読みの言葉、四字熟語、ことわざ、慣用句、文語・古語、口語・俗語、敬語が、カードでよく使われるものから並びます。意味での検索、分類、漢字を含む単語に使う索引は、数秒かけて一度だけ作られ、保存されます。作り直すのは辞書が変わったときだけです。

**文字の大きさと書体。** 検索欄の横の **−** と **+** で単語の大きさを変え、その隣のボタンで全幅表示と中央寄せを切り替えます。**設定、辞書、辞書ページ**では、日本語の**書体**も選べます。画数の多い漢字も読みやすい既定の**ゴシック体**、Kotonoha の**丸ゴシック体**、**明朝体**、筆の運びに沿った日本の教科書体の**手書き**です。システムのフォントを使うため、ない書体はいちばん近いもので代わりに表示します。

**もう知っている文法。** 文法項目はそれぞれ**未習**・**学習中**・**習得済み**に分けられます。字幕の下の項目を押して開く吹き出し、単語パネル、**JLPT** 画面、辞書のどこからでも変えられます。習得済みの項目は字幕の下に示されなくなり、学習中の項目には黄色い線が付きます。動画の行にある項目が出てくるたびに Kotonoha が記録し、**見かけた場所**にその項目が出てきた動画と最後の文が表示されます。**選択式カード**は、穴あきの文と 4 つの選択肢（うち 3 つは Claude が選んだ紛らわしい項目）を表に、答えと他の選択肢が合わない理由を裏にしたカードをカード作成に用意します。**設定 → Anki** の **Anki から文法を取り込む**は、デッキの指定したフィールドから Kotonoha が知っている項目、つまり JLPT リストの 501 項目を探します。間隔が 21 日以上のカードのものは習得済みになります。

**イマージョン時間。** Kotonoha は、学んでいる言語で聞いたり読んだりした時間を数えます。その言語の字幕が付いた再生中の動画（自分のファイルも含む）、ビューアーで開いた本、そして読んでいる間のノートやライブラリのテキストです。読んでいる間とは、ページが見えていて、直近 3 分以内にそのページで何か操作した状態のことです。一時停止中の動画は数えません。**ホーム**には、今日、直近 7 日、合計の時間、1 日 5 分以上の日が続いた**連続**日数、曜日ごとの棒、いちばん多く見たもの・読んだものが表示されます。言語ごとに別々に数え、バックアップにも含まれます。

## 英語を学ぶ

言語はようこそ画面、**設定、言語とレベル**、または拡張機能のメニューで選びます。言語ごとに単語、辞書、カード、ライブラリ、読みの設定が別々にあり、戻っても何も変わりません。表示言語、Claude のキー、費用は共通です。

このガイドの内容はすべて同じように使えます。違いは次のとおりです。

| 項目 | 英語の場合 |
|---|---|
| 辞書 | 表示言語の Wiktionary で、定義と短い訳の 2 つに分かれています。表示言語が英語の場合は英英辞書を提案します。ダウンロードは約 110 MB、保存には約 220 MB 必要です |
| 発音 | 単語パネルにアメリカ英語とイギリス英語の IPA を表示します。単語の上の表示は最初はオフで、**表示**パネルでオンにします。どちらを書くかは**設定、言語とレベル**で選びます |
| 音声変化 | 単語パネルの**音声変化**タブは、続けて話したときの文を、変わる部分の上に実際の音を書いて示します。短縮（*going to* → *gonna*）、弱形（*to* → *tə*）、連結（*turn off* → *tur‿noff*）、t・d と *you* の融合（*meet you* → *meechu*）、アメリカ英語の柔らかい t（*get it* → *ge‿dit*）を説明付きで表示します。Claude は使わず、規則で計算します |
| アクセントの色 | 強勢のある音節を示します。最初、中間、最後の音節です。これも最初はオフです |
| 語形 | パネルが各語形の元の単語を示します。*went* は *go* を、*didn't* は *do* を開きます |
| 句動詞 | 離れていてもパネルが探します。*picked it up* では *pick up* が表示されます。決まり文句も同じです |
| 文法 | A1 から C2 までの文法項目を、同じように Claude が確認します |
| ページリーダー | 英語はほとんどのページにあるので、最初はオフです。拡張機能のメニューまたは**設定、ページリーダー**でオンにします |
| 書き順と読みの修正 | ありません |
| コミック | ビューアーの**コミック**モード（日本語では**漫画**）は、吹き出しごとに本の認識器で、コマ順に左から右へ読みます。実測：テスト用ページで文字誤り率 0.4 %、1922 年の手描き文字の *Krazy Kat* のページで 12 % |
| 本の OCR | 19 世紀の実際のスキャンで実測：文字誤り率 1.5 %、ほとんどがページの見出し |
| 文の音声 | **設定、音声**の**ブラウザーのニューラル音声**は、キーなしでこのパソコンの Kokoro で文を読みます。アメリカとイギリスの 6 種類の声があります。最初に 92 MB をダウンロードし、新しい文はプロセッサーで数秒かかり、その後は保存されます |

## ドイツ語を学ぶ

英語と同じように選び、すべて同じように使えます。違いは次のとおりです。

| 項目 | ドイツ語の場合 |
|---|---|
| 辞書 | 表示言語の Wiktionary（定義と短い訳）に、ドイツ語–英語の辞書が加わります。この辞書は各単語の活用形と格変化形を含むので、常に提案されます。ダウンロードは約 17 MB です。表示言語がドイツ語の場合は、独独辞書（約 55 MB）も提案します |
| 語形 | パネルは各語形の元の単語を開き、どの形かを示します。*ging* は *gehen*（過去形）を、*Häuser* は *Haus*（複数形）を開きます。*schönen* のように 2 つの単語から来うる場合は、よく使われる方を選びます。冠詞は *der* と *ein* に、*sein* の各形は *sein* にまとめます |
| 分離動詞 | 前つづりが文末にあってもパネルが探します。*fängt morgen an* では *anfangen* が表示されます。決まり文句も同じです |
| 発音 | 単語パネルに地域差を除いた IPA を表示します。単語の上の表示は最初はオフで、強勢のある音節を示すアクセントの色も同様です |
| 文法 | Perfekt、Konjunktiv、受動態、動詞が文末に来る従属節など A1 から C2 までの文法項目を、同じように Claude が確認します |
| 文字起こし | 話し声には Parakeet、歌には Whisper Turbo を使います。実際の録音では、Parakeet は大文字と句読点を付け、Whisper の半分以下の時間で終えました |
| ページリーダー | 最初はオフです。拡張機能のメニューまたは**設定、ページリーダー**でオンにします |
| 書き順と読みの修正 | ありません |
| コミック | 英語と同じ**コミック**モード、ä、ö、ü、ß に対応：テスト用ページで誤り率 0.4 % |
| 本の OCR | 現代の書体はよく読めます：4 書体のテスト用ページで誤り率 0.03 %。古い本のひげ文字（Fraktur）は読めません：1919 年のページで 4 文字のうち 3 文字を誤りました |
| 文の音声 | **ブラウザーのニューラル音声**は、キーなしでこのパソコンの Piper と Thorsten の声で文を読みます。最初に 63 MB をダウンロードし、1 文を 1 秒以内に読みます |

## Claude の費用

ホーム画面の **Claude の費用**カードには、設定で入力したクレジットに対する今月の費用、日別・モデル別のグラフ、作業の内訳、トークン付きのリクエスト記録が表示されます。費用は API が報告するトークンと公開価格で計算し、このブラウザのこの拡張機能からのリクエストだけを数えます。

動画あたり最も費用がかかるのは自動字幕の修正で、次に翻訳と、読み方、意味、文法の確認です。確認は再生位置の数分先までを対象にし、再生に合わせて進み、確認済みの内容は保存されます。**字幕を生成**でオフにしたり、**動画全体を確認**で動画全体を頼んだりできます。[費用の調査](costs.md)に動画ごと、月ごとの実測値があります。

単語の問い合わせの使用量を決める設定は 3 つです。

| 設定 | 場所 | 既定 | 効果 |
|---|---|---|---|
| 単語を開くときに意味を尋ねる | 設定、Claude | オフ | 新しい単語を開くたびにリクエストになります |
| 台本全体を文脈に | 設定、Claude | オフ | 名前や指示語の文脈が増える代わりに、問い合わせごとの費用が上がります |
| 最初のタブ | 設定、辞書 | 辞書のみ | Claude のタブにすると単語を開くたびに尋ねます |

## データとバックアップ

すべてのデータはブラウザの IndexedDB に保存されます。**設定、あなたのデータ**で、使ったすべての言語の単語、カード、コレクションとノートを含むライブラリ、生成した字幕、修正、イマージョン時間、文法の印と、設定、費用の記録を含む 1 つのファイルを書き出し、読み込めます。API キーと辞書は含まれません。バージョン 0.4.0 より前のバックアップは日本語として復元されます。

**完全なコピー。** **フォルダーに書き出す**は、本のファイル、OCR が読み取った内容と編集した内容、音声入力も、日付の付いたフォルダーに保存します。**フォルダーから復元**は、既にあるものを消さずに、すべてを別のコピーに入れます。コピーごとにデータを別々に持つので、Kotonoha を別のパソコンや、固定の識別子でインストールしたコピーに移すときに使います。辞書とモデルは設定から入れ直します。

**新しいバージョン。** Kotonoha は 1 日に 1 回、GitHub に最新の公開バージョンを問い合わせます。インストール済みより新しければ、**ホーム**と拡張機能のメニューで、そのページへのリンクと一緒にお知らせします。あるバージョンのお知らせを閉じると、次のバージョンまで表示されません。**設定、バージョン**では、インストール済みのバージョンの確認、手動での確認、**新しいバージョンを知らせる**による通知のオフができます。ヘルパーがインストールされていて、フォルダーから読み込んだコピーなら、お知らせと**設定、バージョン**に**今すぐ更新**が表示されます。ヘルパーがパッケージをダウンロードし、そのバージョンの `SHA256SUMS.txt` で SHA-256 を確認して、識別子を保ったまま拡張機能のフォルダーにコピーし、実行中の処理がなくなりしだい拡張機能が自動で再読み込みされます。ストアからのコピーは自動で更新されます。

## よくある問題

| 症状 | 原因と解決方法 |
|---|---|
| コンパイルしても何も変わらない | ブラウザが以前のサービスワーカーを保持しています。拡張機能のページで**再読み込み**を押す必要があります |
| 「動画を聞くには音声キャプチャをオンにしてください」 | Chrome はタブのキャプチャにユーザーの操作を求めます。動画のタブで `Alt+Shift+M` または拡張機能のメニューのスイッチを使うと解決します |
| `Alt+Shift+M`、`Alt+Shift+K`、`Alt+Q` などのショートカットが反応しない | Chrome は、他の拡張機能が持つキーを、その拡張機能が無効でも割り当てず、通知もしません。拡張機能のメニューとショートカットパネルに実際のキーが表示され、`chrome://extensions/shortcuts` で変更できます |
| `Alt+R` や `Alt+Z` で Radeon Software が開く | AMD のグラフィックスのパソコンでのそのアプリのショートカットです。Kotonoha は `Alt+Shift+M` と `Alt+V` を使います |
| 画面にぼかしが出ない | ハードウェアアクセラレーションがオフだと、動画の上のぼかしでフレームが落ちるので、拡張機能はより濃い背景に置き換えます |
| Whisper がとても遅い | ブラウザが GPU にアクセスできません。ブラウザの設定のハードウェアアクセラレーションを確認してください |
| ヘルパーがインストール済みと表示されない | インストーラーの実行後に拡張機能を再読み込みする必要があります。別のフォルダから読み込んだ場合は `-Extension` で識別子を指定します |
| 動画をダウンロードできない | 年齢制限、非公開、有料の動画は yt-dlp で取得できません。再生しながら文字起こしできます |
| YouTube の字幕が空になる | リクエストはプレーヤーが署名しています。動画を数秒再生すれば解決します |
| Anki に接続できない | AnkiConnect を入れた Anki を開いておき、その設定で拡張機能のオリジンを許可する必要があります。拡張機能は最初に許可を求めます |
