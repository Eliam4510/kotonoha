# 功能

版本 0.25.0 中每项功能的状态及其验证方式。

| 验证方式 | 含义 |
|---|---|
| 自动 | 在加载了扩展的 Edge 中端到端测试 |
| 模拟器 | 真实代码完整运行，对接 Claude API 或 AnkiConnect 的模拟服务器 |
| 模仿页面 | 另外在播放器结构与 Netflix 或 YouTube 相同的页面上测试 |
| 真实会话 | 在 YouTube 上用 Chrome、真实会话和 Claude API 手动检查 |
| 待验证 | 需要网站的真实会话或自己的凭据 |

## 设计原则

| 原则 | 体现 |
|---|---|
| 含义取决于句子 | “在这句话中”区块给出语境中的含义，指出比喻或诗意的用法，并排在卡片首位 |
| 正确的读音 | Claude 检查每行的读音，也可以手动更正 |
| 充足的上下文 | Claude 收到句子前后的 40 行及其翻译。更正时发送完整脚本，查询时可选 |
| 绝不重复付费 | 每个回答按单词和句子保存，已检查的内容按行文本保存。中断的回答会完成并保存，同时发出的相同查询共用一个请求 |
| 只在需要时使用 Claude | 面板以词典打开，检查覆盖即将观看的部分而不是整部视频 |
| 从正在观看的部分开始 | 翻译、更正和检查都按播放位置排列各段 |
| 电脑依然可用 | 转录会休息，会根据使用情况调整，并在反复失败时停止 |
| 不重写页面 | 网页下划线使用 CSS Custom Highlight API，不向内容添加任何东西。只在注音放不下时拉开行距 |
| 本地数据 | 一切都保留在浏览器中，转录的音频不会离开电脑 |

## 已知限制

| 限制 | 详情 |
|---|---|
| 学习语言 | 日语、英语和德语。每种新语言都需要自己的语言包，位于 `src/lenguas` |
| 英语分析 | 由一个能放进扩展的小模型完成。遇到有歧义的句子时可能判错词性，单词下方的翻译也会随之出错。单词面板仍会显示所有释义 |
| 德语分析 | 依据词典中的词形：没有德英词典时，每个词就是它自己的原形。两个可能的词之间按频率决定，不看句子；Claude 检查该行时会更正错误 |
| 德语复合词 | 词典中没有的复合名词不会拆分成各个部分 |
| 英英词典 | 体积较大：下载约 110 MB，占用约 220 MB。安装和删除需要几分钟。只在界面为英语时建议安装 |
| 界面翻译 | 借助 AI 编写，尚未经过母语者审校。错误在 `idiomas/` 中更正 |
| 网页阅读器 | 只作用于主框架：无法处理 iframe 内的文本。页面绘制在画布或图片中的内容不是文本 |
| Claude 提示词 | 指令仍为西班牙语，要求用其他语言回答时也是如此 |
| 平台 | 桌面版 Chrome 和 Edge。本地助手为 Windows 准备 |
| 带 DRM 的图像 | 在 Netflix 和其他受保护的网站上，浏览器提供的画面是黑色的。如果网站提供，卡片会使用该集的官方图片 |
| 带 DRM 的音频 | 受保护的网站可能不向捕获提供声音。同一视频中连续两句无声后，不再为录音而重新播放 |
| 查看器 | 文字识别可能混淆相似的字符（エ 和 工，ー 和 一），偶尔漏字，并丢失公式的下标；原始图像始终可见。书模式是用横排文字测量的。带 DRM 的书无法打开。书的文件不包含在单个文件的备份中，但包含在完整副本中。文字版 EPUB 按章节滚动阅读，而不是按页翻；漫画模式下点的是整个对话框，而不是单个词。 |
| 同步 | 没有服务器：在电脑之间转移数据要通过完整副本 |
| 背景音乐 | 在响亮的音乐下，Whisper 可能漏掉低声对话 |
| 歌词 | 时间按 Whisper 的行计算，而不是按词。音乐很响时 Whisper 可能听到的很少，这时会有更多句子使用估算时间 |
