# Claude API 费用

使用自己的 Claude API 密钥运行 Kotonoha 的费用，于 2026 年 11 月 5 日用真实视频测得。首页的 **Claude 费用**卡片根据 API 报告的 token 显示每个安装的准确用量。

字幕、词典、注音、卡片、复习和 Whisper 转录都不使用 API，不产生费用。

## 摘要

以每月 100 美元的参考额度计算：

| 视频使用方式 | 每小时费用 | 100 美元每月可用小时数 |
|---|---|---|
| 自动字幕，含更正、检查和翻译 | 1.39 USD | 62 |
| 自动字幕，含更正和检查 | 1.00 USD | 82 |
| 人工字幕，含检查和翻译 | 0.75 USD | 104 |
| 人工字幕，含检查 | 0.36 USD | 175 |

最后一列的小时数包含每小时视频 30 次单词查询。重看视频不产生费用，因为已检查、更正和翻译的内容都会保留。

## 测量

每项费用取自操作前后的 Claude Console 余额，使用默认模型和力度。余额精确到一美分，因此每个数字有 ±0.01 USD 的误差。

| 操作 | 视频 | 实测费用 |
|---|---|---|
| 检查读音、词义和语法 | 6:41，人工字幕 | 0.04 USD |
| 更正和检查 | 10:46，自动字幕，154 行 | 0.18 USD |
| 翻译成西班牙语 | 同一视频，150 行 | 0.07 USD |
| 句中含义，以完整脚本作为上下文 | 5 个单词 | 0.03 USD |

折算为每小时视频的费率如下。更正的费用由第二项测量减去检查得出。

| 任务 | 每小时视频 | 每 10 分钟 |
|---|---|---|
| 更正自动字幕 | 0.64 USD | 0.11 USD |
| 翻译 | 0.39 USD | 0.07 USD |
| 检查读音、词义和语法 | 0.36 USD | 0.06 USD |

费用取决于说话的多少。这些视频每分钟约 14 行，对话更多的视频费用按比例增加。

## 如何避免花费

| 措施 | 效果 |
|---|---|
| 面板以词典打开 | 鼠标悬停在单词上不再发送任何请求 |
| 每个回答按单词和句子保存 90 天 | 在单词之间来回切换或回到同一视频都不产生费用 |
| 进行中的请求不会取消 | 切换单词不会浪费已付费的内容：它会完成、保存并可用 |
| 同时发出的相同查询共用一个请求 | 不会因为着急而付两次钱 |
| 检查随视频推进 | 看了 10 分钟就放弃电影，不必为整部电影付费 |
| 完整脚本在查询时可选 | 每次查询发送 40 行上下文，而不是整部视频 |

## 如何少花钱

| 设置 | 位置 | 每小时视频节省 |
|---|---|---|
| 只在需要时翻译 | 生成字幕 | 0.39 USD |
| 不随播放检查 | 生成字幕 | 0.36 USD |
| 打开时不更正自动字幕 | 生成字幕 | 0.64 USD |
| 按任务使用较小的模型或较低的力度 | 设置、Claude | 取决于任务，可能影响质量 |

前三项仍可在需要的视频上用相应按钮请求。
