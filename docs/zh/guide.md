## 开始使用

首次使用时会打开欢迎页，询问语言、要学习的语言和水平，并建议安装词典、添加 Claude 密钥以及选择卡片的保存位置。可以跳过，之后可在**设置、外观**中再次查看。其他内容都在扩展窗口的**设置**中配置，窗口用 `Alt+Shift+K` 打开。

| 步骤 | 位置 | 用途 |
|---|---|---|
| 词典 | 设置、词典 | 西班牙语、英语或德语的 JMdict，Kanjium 的音调重音和 JPDB 的频率。只下载一次，保存在浏览器中 |
| Claude API 密钥 | 设置、Claude | 解释、读音检查、翻译和更正。只保存在浏览器中 |
| 语言和水平 | 设置、语言和水平 | 界面语言，以及单独设置的解释和翻译语言。水平会调整解释的方式，并决定一开始显示多少注音 |
| 正在学习的语言 | 设置、语言和水平，扩展菜单，或视频上的**视频设置、字幕** | 日语、英语或德语。每种语言都保存自己的单词、词典、卡片和设置 |
| Anki | 设置、卡片和 Anki | 可选。需要打开 Anki 并安装 AnkiConnect 插件 |

扩展无需 Claude 密钥也能使用：字幕、词典、注音、颜色、卡片和 Whisper 都不需要它。

### 个性化

| 选项 | 位置 | 用途 |
|---|---|---|
| 罗马字读音 | 设置、语言和水平 | 适合还不会读假名的人。适用于字幕、单词面板和网页 |
| 单词颜色 | 设置、外观 | 三种配色：默认配色、不靠红绿也能区分的色盲友好配色，以及高对比度配色 |
| 快捷键 | 设置、键盘快捷键 | 视频上的快捷键在这里更改。浏览器使用的快捷键（如音频捕获）在浏览器的快捷键页面更改 |
| 费用上限 | 设置、Claude | 达到上限后，Claude 在下个月之前不再使用 |
| 不使用阅读器的网站 | 设置、网页阅读器，或页面边缘的按钮 | 只在造成干扰的网站上关闭 |

## 视频上的界面

打开带日语字幕的视频时，顶部会出现一个浮动工具栏，显示估算的理解度、推荐句子、已知单词和播放模式。它会自动隐藏，鼠标停在顶部边缘时重新出现，鼠标在附近时一直显示。

**字幕。** 每个单词都带有注音、按音调重音显示的颜色，以及按状态显示的下划线：未知、追踪、已知或忽略。识别到的语法点以标签显示。

**移动字幕。** 可以从任意位置（包括单词上）拖到喜欢的高度和位置。位置对所有视频生效，并按视频大小等比保持，影院模式下也一样。双击背景，或在显示设置中点击**恢复原位**，即可还原。

**单词面板。** 鼠标悬停在单词上会打开单词面板，不向 Claude 发送任何请求，内容包括释义、频率、音频、图片、例句、笔顺，以及指向 Jisho、JapanDict、Weblio、Goo、Kotobank、Wiktionary、Forvo 和 Massif 的链接。JapanDict 的链接打开 JMdict 的确切条目，而不是同形词列表。

**在这句话中。** 有 Claude 密钥时，**在这句话中是什么意思？**按钮会说明单词在此语境中的含义，并指出比喻或诗意的用法。Claude 会收到这句话前后的 40 行及其翻译。**解释**、**解析**和**翻译**标签页同样如此：点击时才发出请求。所有回答都会保存，再次查看这句话中的这个单词不产生费用，面板上会显示**已保存，无费用**。**深入了解**按钮使用 Opus 5.5 重新查询。

**笔顺。** 单词面板的**笔顺**标签页展示单词中每个汉字的写法：笔画逐一绘制，循环播放并标有序号。可以暂停、逐笔前进和更改速度。数据来自 [KanjiVG](https://kanjivg.tagaini.net)：每个汉字在首次使用时下载，并保存在浏览器中。

**字幕导航。** 按 `G` 打开侧边面板，其中有所有字幕行、筛选、书签和多选功能，还可以合并字幕行、批量制卡和同步。

**播放模式。**

| 模式 | 行为 |
|---|---|
| 普通 | 正常播放，不暂停也不隐藏字幕 |
| 预习式听力 | 每句话之前暂停并显示翻译 |
| 精读 | 每句话之前暂停，先读后听 |
| 精听 | 隐藏字幕直到句子说完，然后暂停并显示 |
| 强化混合 | 每句话之后暂停，字幕保持可见 |
| 暂停时显示 | 只在视频暂停时显示字幕 |
| 1D 聚焦 | 在只有一个未知词的句子处停下 |
| 自定义 | 可调整暂停和遮罩 |

没有对话的场景可以在视频面板中设置为加速或跳过。

## 字幕

### 选择字幕轨

**视频和字幕**面板的**字幕**标签页用于选择日语字幕轨和第二字幕。默认情况下，人工字幕优先于自动字幕，导入的字幕优先于所有其他字幕。

### 用 Claude 翻译

**AI 字幕**面板中的翻译按钮，或第二字幕旁的**用 Claude 翻译**，会把日语字幕翻译成辅助语言：西班牙语、英语、葡萄牙语、法语或德语。

- 从正在观看的部分开始，这一部分几秒内就能完成。
- 结果陆续显示。
- 取消后，已翻译的内容会保留，再次点击只请求缺少的行。

### 更正自动字幕

自动字幕经常混淆同音词。Claude 以标题和全文作为上下文进行更正，不会提问。

- 自动字幕轨默认开启，可在面板中关闭。
- 只更改有明显错误的内容。Claude 认为是识别系统编造的行会被删除。
- 更正会被保存，不再重复请求。
- 导航中会标出已更正的行，并可查看原文。

### 从其他语言生成日语

只有其他语言的字幕时，Claude 可以把它们改写成日语。这是翻译的翻译，不会与听到的内容完全一致。如果有日语字幕文件，总是更好的选择。

### 导入和导出

每条字幕轨都有**导入**和**导出 SRT** 按钮，也可以把文件拖到视频上。支持 SRT、VTT、ASS、SSA、TTML 和 DFXP。

- 导入的内容按标题保存，并优先于网站的字幕轨。
- 导出时包含同步调整。

### Netflix 地区

观看 Netflix 作品时，其日语字幕会连同作品标识符一起保存。如果其他地区的目录提供同一作品但没有这条字幕轨，Kotonoha 会将其显示为“日语（已保存）”，并把该地区提供的字幕作为第二字幕。导出 SRT 再导入文件，可以手动实现同样的效果。

### 同步

**同步**标签页用于调整每条字幕轨的偏移。也可以在导航中使用**同步：此行正在播放**：一个标记校正偏移，两个标记还会校正速度。偏移可用 `Alt+I` 和 `Alt+O` 调整。

## 用 Whisper 转录

视频没有字幕时，Whisper 可以生成日语字幕。它通过 WebGPU 在显卡上运行，音频不会离开电脑。首次使用时会下载模型并保存在浏览器中。Netflix 上不提供此功能，因为其作品几乎都有字幕。

| 来源 | 需要什么 | 速度 |
|---|---|---|
| 应用播放器中的本地文件 | 无 | 每 30 分钟视频约 5 分钟 |
| 网络视频，使用本地助手 | 安装助手 | 每 30 分钟视频约 5 分钟，另加下载时间 |
| 网络视频，不使用助手 | 用 `Alt+Shift+M` 或扩展菜单中的开关开启音频捕获 | 实时，延迟几秒 |

**模型。**

| 模型 | 下载大小 | 用途 |
|---|---|---|
| 自动 | | 默认。日语口语用 Haas-ja，英语和德语口语用 Parakeet，歌曲用 Whisper Turbo |
| Haas-ja | 1.3 GB | 仅限日语。对口语最准确也最快，有背景音乐时同样如此，并带标点 |
| Parakeet | 1.3 GB | 英语和德语。对口语最准确也最快，有背景音乐时同样如此，带标点，时间也最精确 |
| Whisper Turbo | 1.5 GB | 最适合歌曲 |
| Whisper Turbo 轻量版 | 564 MB | 准确度略低，占用显存更少 |
| Whisper Base | 165 MB | 用于没有高性能 GPU 的电脑 |

在自动模式下，如果已粘贴歌词、网站将视频归类为音乐，或标题中写明，例如“MV”或“歌ってみた”，视频就被视为歌曲。对于日语口语，Haas-ja 的错误率为 3%，Whisper Turbo 为 9%，转录 30 分钟约需 1 分钟，而 Whisper 约需 5 分钟。对于歌曲，它只写出所唱内容的一部分，此时 Whisper Turbo 更好。英语中 Parakeet 也是如此：错误率 6.8%，Whisper Turbo 为 9.6%，时间精确三倍。转录时，面板会显示正在工作的模型。

模型保存在浏览器中，不会重新下载：每次都从磁盘读取，可能需要几秒钟。在**设置、语音转录、已保存的模型**中可以查看每个模型占用的空间并将其删除。卸载扩展程序也会删除它们。

**强度。** 决定显卡工作的时间比例。其余时间休息，如果其他应用正在占用显卡，休息时间会自动增加。

| 强度 | 占用率 | 30 分钟视频 |
|---|---|---|
| 自动 | 使用电脑时 75%，闲置两分钟后 90% | 约 5 分钟 |
| 柔和 | 30% | 约 12 分钟 |
| 快速 | 90% | 约 4 分钟 |

转录期间可以暂停以立即释放显卡，并从同一位置继续。如果显卡驱动程序重启，Whisper 会等待 20 秒，重新加载模型，并以最低强度继续。第二次失败时停止，已转录的内容会保留。

### 歌词

Whisper 的时间很准，但在歌曲中会听错很多词。如果有人发布了歌词，例如在视频评论中，可以把它粘贴到 **AI 字幕** 面板的 **歌词** 中，Claude 会把它放到这些时间上。

- Claude 只指出哪一句对应转录的哪几行。词语完全来自歌词，时间来自 Whisper。
- 如果在转录之前或转录期间粘贴歌词，结束时会自动对齐，也不会花钱更正或检查 Whisper 听到的内容。如果视频已有字幕轨，也可以通过 **把歌词对齐到这些时间** 用它作为时间参考。
- 只写了一次的副歌会放到每个唱到它的地方。不唱的内容，例如段落标记、罗马字或翻译，会被忽略。
- Whisper 没有听到的句子会得到估算的时间，最后的提示会说明有多少句。这时可以用导航器中的 **同步：此行正在播放** 微调。
- 结果是另一条字幕轨“日语 (歌词)”，保存在该视频下。原来的转录仍然可用。每首歌只向 Claude 发送一次请求，用相同歌词再次对齐不会再产生费用。
- 对于没有本地助手的网络视频，Whisper 必须听完整首歌：视频结束时转录会自动停止，然后对齐歌词。

### 本地助手

扩展无法自行下载视频的音频。助手是一个小型本地程序，使用 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 和 FFmpeg 完成这项工作。它需要 Python，安装程序会在缺少时添加 yt-dlp。只需在项目文件夹中安装一次：

```bash
powershell -ExecutionPolicy Bypass -File herramientas\ayudante\instalar.ps1
```

然后需要在 `edge://extensions` 或 `chrome://extensions` 中重新加载扩展。状态可在**设置、转录**中查看。

| 方面 | 行为 |
|---|---|
| 范围 | 只有扩展可以调用它，且只接受 http 或 https 地址 |
| 注册 | 在 `HKCU` 中添加一个用户级键，无需管理员权限 |
| 文件 | 使用临时文件夹，完成或取消时删除 |
| 标识符 | 如果从其他文件夹加载扩展，其标识符会改变：用 `-Extension` 指定，标识符显示在扩展页面上 |
| 卸载 | 同一命令加 `-Quitar` |

如果视频无法下载（例如私有或有年龄限制），提示中会建议在播放时转录。

## 卡片

| 快捷键 | 操作 |
|---|---|
| `Q`、`Alt+Q` | 用当前单词和句子创建卡片 |
| `E` | 把鼠标下的单词、选中内容或图片发送到制卡器 |

卡片可以通过 AnkiConnect 发送到 Anki（使用自己的笔记类型或扩展创建的笔记类型），也可以保存到**记忆库**，即使用 FSRS 的内置复习。字段包括句子、注音、翻译、释义、音频、图片和备注。音频捕获用 `Alt+Shift+M` 或扩展菜单中的开关开启。

**视频的音频和图像。** 要录制句子的音频，需要在视频所在的标签页中开启捕获，方法是按 `Alt+Shift+M` 或使用扩展菜单中的开关。捕获仅限该标签页：如果在其他标签页中开启，麦克风图标显示为关闭，卡片不带音频。创建卡片时，该行会以正常速度重新播放并录制，然后视频回到原来的位置。图像不包含任何界面元素。在 Netflix 等使用 DRM 的网站上，浏览器提供的画面是黑色的：卡片会改用该集的官方图片，如果网站没有提供则不带图片。受保护的网站也可能不提供声音：卡片不带音频，同一视频中连续两句无声后，不再为录音而重新播放。

## 网页、阅读器和书库

**网页。** 在任何含日语文本的页面上，阅读器都会按掌握程度为单词加下划线并添加注音。单击单词打开单词面板。在链接和按钮上，单击仍属于网站，鼠标停留时打开单词面板，按 `Shift` 则立即打开。拖动仍然用于选择文本，面板打开时可使用 `1` 至 `4` 和 `Q`。

右侧边缘的按钮可以在不离开页面的情况下调整颜色和注音，扩展菜单用于开关阅读器。注音有四种模式：所有单词、仅新词、鼠标悬停时或从不。在**设置、网页阅读器**中，可以让面板始终在悬停时打开，或让单击链接时也查词。

这些都不会向页面内容添加任何东西。颜色使用 CSS Custom Highlight API，读音位于单独的图层，因此选择、复制和搜索一如既往，也不会干扰用 React 等构建的应用。它也适用于在框内滚动的内容，例如聊天对话：注音随文字移动，并从输入框下方经过。它不作用于输入框以及中文或韩语文本。

**拉开行距。** 许多页面的行距很小，注音会与上一行相碰。这时会把这段文字的行距拉开到刚好够用，这也是阅读器唯一可能移动页面的地方。按钮和菜单不会这样处理，文字会超出固定高度的框时也不会：这些情况下如果完全没有空间，注音会留到鼠标悬停时显示。边缘按钮中的**拉开行距**开关可以关闭此功能，此时布局完全不动。

`Alt+K`、`Alt+U` 和 `Alt+I` 把选中的文本批量标记为已知、未知或忽略。

**剪贴板。** 以与字幕相同的辅助功能显示任何粘贴或复制的文本，并保留其结构：段落、换行、标题、列表、引用、代码、表格和粗体。从页面复制的内容不带该页面的注音，从 Claude 聊天复制的 Markdown 保留其格式。

**网页模式。** 应用窗口没有标签页，因此无法进入浏览器的分屏视图。剪贴板的**网页模式**按钮会在普通标签页中打开它（没有侧边栏），扩展菜单中的**在此标签页旁打开剪贴板**则把它直接放在正在查看的页面旁边（Chrome 155 或更高版本）。在该标签页中，**跟随剪贴板**会把在任何地方复制的日语添加到下方，只要标签页保持可见。它是扩展自身的页面：不需要服务器，可离线使用，文本不会离开电脑。

**阅读助手。** 保存在阅读器中打开的 EPUB、CBZ 和 PDF 书籍与图片文件夹，以及文本和 SRT 字幕，记住阅读位置并保留每章的结构。也可以用 Claude 生成符合所设水平的故事。

**查看器。** 由图像组成的 EPUB（如漫画和扫描书）、CBZ 和 PDF 会在查看器中打开，使用独立的标签页，就像 PDF 阅读器一样。它提供缩放（**放大**、**缩小**、**适合宽度**和**整页**，也可以用 Ctrl 加鼠标滚轮）、三种视图（**单页**、**双页**和**连续滚动**）、**缩略图**、书的**目录**以及**全屏**。声明从右向左阅读的书（如漫画）会按此方式显示：左方向键前进，在双页视图中封面可以单独显示，使左右页与印刷版一致。方向键、Home 和 End 用于翻页，F 切换全屏。文件按原样保存在浏览器的存储中并分段读取，不会整个载入，查看器会记住每本书的页码、视图和缩放。

**图片文件夹。** 以图片形式提供的漫画，可以用**选择图片文件夹**或把文件夹拖进来导入。每个包含图片的文件夹都是一本书。如果只包含看起来像分卷的子文件夹（根据名称，如“第01巻”“Vol. 2”“v03”，或因为包含约两百张图片），每一卷会单独导入，名称只有卷号时前面会加上系列名；如果看起来像章节，则成为同一本书的目录。页面按自然顺序排列，即使封面名为“cover.jpg”也会排在最前；非图片文件会被忽略，ComicInfo.xml 提供书名和阅读方向。每本书都保存为 CBZ，不会重新压缩图片，也不会把图片复制到内存中。在**双页**视图中，横向页面（即整张扫描的双页）会单独显示。

**页面文字。** **读取页面上的文字**按钮在本机用 GPU 识别图像页面上的文字，并放在页面上：鼠标悬停时会标出每一行，点击后会在侧边打开，带有注音和可查询的单词，以及单词面板和制卡功能。有两种模式：**书**，用于印刷书籍和扫描的 PDF；**漫画**，用于对话框和竖排文字，不会把注音当成正文。在**书**模式中，印刷的注音不会混入正文，双栏页面逐栏阅读；在**漫画**模式中，对话框按分镜顺序排列，水印和页码会被去掉。从右向左阅读的书默认使用**漫画**模式。已自带文字的 PDF 会使用其自带的文字；如果那是其他文字识别软件留下的、错误较多的文字层，关闭**PDF 文字**后，Kotonoha 也会识别这些页面。第一次使用时会下载模型，书籍 21 MB，漫画 178 MB，每页只识别一次，耗时一到两秒。文字识别可能会混淆相似的字符或丢失公式的下标；原始图像始终可见。后面的页面会在你翻到之前就读取好，所以翻页时文字已经在那里。如果某一行有字认错了，可以在行面板中用**编辑**手动输入它的文字：编辑的内容单独保存，即使页面重新识别也不会丢失，**恢复**则回到识别出的文字。在阅读助手中每本书的卡片上，**处理**会一次性用文字识别读取全部页面，并显示进度；可以暂停，稍后继续而不丢失任何内容，完成后书上会显示**文字已就绪**，并开启文字识别。

**文字书。** 像小说这样的文字版 EPUB 会在阅读器中以原有格式打开：保留章节、CSS、注音、插图和竖排。上面叠加网页阅读器，和在网页上一样：颜色、振假名，点击一个词即可打开它的单词面板。方向键、Page Up、Page Down 和鼠标滚轮用于翻页；竖排的书向左推进，一章读完会进入下一章。**目录**可跳到各章，书中的链接可以使用，**放大**和**缩小**改变文字大小，**竖排文字**可以把竖排的书改为横排阅读。阅读器会记住章节和确切位置。书中的任何内容都不会执行，也不会从网上加载任何东西。

**带文字的 PDF。** 如果 PDF 自带文字，就直接使用，无需 OCR，也不用下载：点一下某一行即可。在页面上点一个词，无论是带文字的 PDF 还是用**书**模式识别的页面，都会直接打开它的单词面板，并在页面上标出这个词。

**本地播放器。** 播放本地文件，通过 ffmpeg.wasm 支持 MKV 内嵌字幕和音轨选择。

**单词和评估。** 单词浏览器按状态列出词汇，水平评估估算初始已知词量。

## 学习英语

语言可在欢迎页、**设置、语言和水平**或扩展菜单中选择。每种语言都有自己的单词、词典、卡片、书库和阅读设置，切换回来时一切如旧。界面、Claude 密钥和费用是共用的。

本指南介绍的内容都同样适用，区别如下：

| 项目 | 英语 |
|---|---|
| 词典 | 界面语言的 Wiktionary，分两部分：释义和简短翻译。界面为英语时，建议使用英英词典，下载约 110 MB，占用约 220 MB |
| 发音 | 单词面板中显示美式和英式 IPA。单词上方默认关闭，可在**显示**面板中开启。写哪一种在**设置、语言和水平**中选择 |
| 重音颜色 | 表示重读音节：第一个、中间或最后一个。同样默认关闭 |
| 词形 | 面板指出每个词形来自哪个词：*went* 打开 *go*，*didn't* 打开 *do* |
| 短语动词 | 即使被拆开，面板也会查找：*picked it up* 中会出现 *pick up*。固定搭配也一样 |
| 语法 | A1 到 C2 的语法点，同样由 Claude 确认 |
| 网页阅读器 | 默认关闭，因为几乎每个页面都有英语。可在扩展菜单或**设置、网页阅读器**中开启 |
| 笔顺和读音更正 | 不提供 |

## 学习德语

选择方式与英语相同，所有功能用法一样，区别如下：

| 项目 | 德语 |
|---|---|
| 词典 | 界面语言的 Wiktionary，包括释义和简短翻译，另加德英词典。德英词典总会被推荐，因为它包含每个词的变位和变格形式：下载约 17 MB。界面为德语时还会推荐德德词典，约 55 MB |
| 词形 | 单词面板打开每个形式所属的词，并说明是哪种形式：*ging* 打开 *gehen*（过去时），*Häuser* 打开 *Haus*（复数）。如果一个形式可能来自两个词，例如 *schönen*，则取更常用的那个。冠词归到 *der* 和 *ein*，*sein* 的各种形式归到 *sein* |
| 可分动词 | 即使前缀位于句末，单词面板也会查找：*fängt morgen an* 会显示 *anfangen*。固定搭配同理 |
| 发音 | 单词面板中显示 IPA，不含地区变体。单词上方的发音默认关闭，表示重读音节的重音颜色也是如此 |
| 语法 | A1 到 C2 的语法点，例如 Perfekt、Konjunktiv、被动态和动词位于句末的从句，并同样由 Claude 确认 |
| 转录 | 口语用 Parakeet，歌曲用 Whisper Turbo。在一段真实录音上，Parakeet 输出了大小写和标点，用时不到 Whisper 的一半 |
| 网页阅读器 | 默认关闭。可在扩展菜单或**设置、网页阅读器**中开启 |
| 笔顺和读音修正 | 不提供 |

## Claude 费用

首页有 **Claude 费用**卡片，显示本月费用与设置中填写的额度对比、按天和模型的图表、任务分布，以及每次请求的日志和 token 数。费用根据 API 报告的 token 和公开价格计算，只统计此浏览器中此扩展发出的请求。

每个视频中花费最多的是更正自动字幕，其次是翻译以及读音、词义和语法的检查。检查覆盖播放位置之后的几分钟，并随播放推进；已检查的内容会保留。可以在**生成字幕**中关闭，或用**检查整个视频**请求整部视频。[费用研究](costs.md)提供了按视频和按月的实测数据。

有三个设置决定单词查询的使用量：

| 设置 | 位置 | 默认 | 效果 |
|---|---|---|---|
| 打开单词时询问含义 | 设置、Claude | 关闭 | 每打开一个新词就是一次请求 |
| 完整脚本作为上下文 | 设置、Claude | 关闭 | 为名称和指代提供更多上下文，每次查询费用更高 |
| 初始标签页 | 设置、词典 | 仅词典 | 选择 Claude 标签页会在打开每个单词时发出请求 |

## 数据和备份

所有数据都保存在浏览器的 IndexedDB 中。**设置、你的数据**可以导出和导入一个文件，其中包含每种用过的语言的单词、卡片、书库、生成的字幕和更正，以及设置和费用记录。不包括 Claude 密钥和词典。0.4.0 版之前的备份会按日语恢复。

## 常见问题

| 症状 | 原因和解决方法 |
|---|---|
| 编译后没有变化 | 浏览器保留了之前的 Service Worker。需要在扩展页面点击**重新加载** |
| “要听到视频需要开启音频捕获” | Chrome 要求用户操作才能捕获标签页。在视频所在的标签页中按 `Alt+Shift+M` 或使用扩展菜单中的开关即可 |
| `Alt+Shift+M`、`Alt+Shift+K` 或 `Alt+Q` 等快捷键没有反应 | Chrome 不会把其他扩展已占用的按键分配给扩展（即使那个扩展已停用），也不会提示。扩展菜单和快捷键面板显示实际按键，可在 `chrome://extensions/shortcuts` 中更改 |
| `Alt+R` 或 `Alt+Z` 打开 Radeon Software | 这是该应用在 AMD 显卡电脑上的快捷键。Kotonoha 使用 `Alt+Shift+M` 和 `Alt+V` |
| 界面没有模糊效果 | 关闭硬件加速时，视频上的模糊效果会丢帧，因此扩展改用更不透明的背景 |
| Whisper 非常慢 | 浏览器无法访问 GPU。应检查其设置中的硬件加速 |
| 助手没有显示为已安装 | 运行安装程序后需要重新加载扩展。如果扩展是从其他文件夹加载的，需要用 `-Extension` 指定其标识符 |
| 无法下载视频 | 有年龄限制、私有或付费的视频，yt-dlp 无法获取。可以在播放时转录 |
| YouTube 返回空字幕 | 其请求由播放器签名。播放视频几秒即可 |
| Anki 无法连接 | Anki 必须打开并安装 AnkiConnect，其配置必须允许扩展的来源。扩展首次使用时会请求权限 |
