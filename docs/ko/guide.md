## 시작하기

처음 사용할 때 환영 화면이 열려 언어, 공부할 언어, 수준을 묻고, 사전 설치, Claude 키 추가, 카드 저장 위치 선택을 제안합니다. 건너뛸 수 있으며 **설정, 외관**에서 다시 볼 수 있습니다. 나머지는 모두 `Alt+Shift+K`로 여는 확장 프로그램 창의 **설정**에서 구성합니다.

| 단계 | 위치 | 용도 |
|---|---|---|
| 사전 | 설정, 사전 | 스페인어, 영어 또는 독일어 JMdict, Kanjium의 고저 악센트, JPDB의 빈도. 한 번 내려받아 브라우저에 보관합니다 |
| Claude API 키 | 설정, Claude | 설명, 읽는 법 검토, 번역, 수정. 브라우저에만 저장됩니다 |
| 언어와 수준 | 설정, 언어와 수준 | 인터페이스 언어와 별도로 설정하는 설명과 번역 언어. 수준은 설명 방식을 조정하고 처음에 후리가나를 얼마나 보여 줄지 정합니다 |
| 공부하는 언어 | 설정, 언어와 수준, 확장 프로그램 메뉴, 또는 영상 위의 **영상 설정, 자막** | 일본어 또는 영어. 언어마다 단어, 사전, 카드, 설정을 따로 저장합니다 |
| Anki | 설정, 카드와 Anki | 선택 사항. AnkiConnect 부가 기능이 설치된 Anki를 열어 두어야 합니다 |

확장 프로그램은 Claude 키 없이도 작동합니다. 자막, 사전, 후리가나, 색상, 카드, Whisper에는 키가 필요하지 않습니다.

### 맞춤 설정

| 옵션 | 위치 | 용도 |
|---|---|---|
| 로마자 읽는 법 | 설정, 언어와 수준 | 아직 가나를 읽지 못하는 사람을 위한 것입니다. 자막, 단어 패널, 페이지에 적용됩니다 |
| 단어 색상 | 설정, 외관 | 세 가지 팔레트: 기본, 빨강과 초록 없이 구별되는 색각 이상용, 고대비 |
| 단축키 | 설정, 키보드 단축키 | 영상 위 단축키는 여기서 바꿉니다. 오디오 캡처처럼 브라우저가 쓰는 단축키는 브라우저의 단축키 페이지에서 바꿉니다 |
| 비용 한도 | 설정, Claude | 한도에 도달하면 다음 달까지 Claude를 사용하지 않습니다 |
| 리더를 쓰지 않는 사이트 | 설정, 페이지 리더 또는 페이지 가장자리의 버튼 | 방해가 되는 곳에서만 끕니다 |

## 영상 위 화면

일본어 자막이 있는 영상을 열면 위쪽에 떠 있는 바가 나타납니다. 예상 이해도, 추천 문장, 아는 단어, 재생 모드를 보여 줍니다. 저절로 숨겨지고, 마우스를 위쪽 가장자리에 멈추면 다시 나타나며, 마우스가 근처에 있는 동안 유지됩니다.

**자막.** 각 단어에는 후리가나, 고저 악센트에 따른 색상, 상태에 따른 밑줄이 표시됩니다. 상태는 모르는 단어, 추적, 아는 단어, 무시입니다. 인식된 문법 포인트는 라벨로 표시됩니다.

**자막 옮기기.** 단어 위를 포함해 어느 지점에서든 끌어서 원하는 높이와 위치로 옮길 수 있습니다. 위치는 모든 영상에 적용되고 영상 크기에 비례해 유지되며, 극장 모드에서도 마찬가지입니다. 배경을 두 번 클릭하거나 표시 설정에서 **제자리로**를 누르면 되돌아갑니다.

**단어 패널.** 단어에 마우스를 올리면 Claude에 아무 요청도 보내지 않고 단어 패널이 열립니다. 정의, 빈도, 오디오, 이미지, 예문, 획순과 Jisho, JapanDict, Weblio, Goo, Kotobank, Wiktionary, Forvo, Massif 링크가 있습니다. JapanDict 링크는 동형이의어 목록이 아니라 JMdict의 정확한 항목을 엽니다.

**이 문장에서.** Claude 키가 있으면 **이 문장에서는 무슨 뜻인가요?** 버튼이 그 맥락에서의 뜻을 알려 주고 비유적이거나 시적인 용법을 표시합니다. Claude는 문장 주변 40줄과 번역을 받습니다. **설명**, **분석**, **번역** 탭도 같은 방식으로, 누를 때 요청합니다. 모든 답변이 저장되므로 그 문장의 그 단어로 돌아와도 비용이 들지 않으며, 패널에 **저장됨, 비용 없음**이 표시됩니다. **더 알아보기** 버튼은 Opus 5.5로 다시 요청합니다.

**획순.** 단어 패널의 **획순** 탭은 단어에 있는 각 한자를 쓰는 법을 보여 줍니다. 획이 번호와 함께 하나씩 그려지며 반복됩니다. 일시정지, 한 획씩 넘기기, 속도 변경이 가능합니다. 데이터는 [KanjiVG](https://kanjivg.tagaini.net)에서 가져오며, 한자마다 처음 한 번 내려받아 브라우저에 보관합니다.

**자막 탐색기.** `G`를 누르면 모든 줄, 필터, 표시, 다중 선택이 있는 사이드 패널이 열립니다. 줄 합치기, 여러 카드 만들기, 동기화도 할 수 있습니다.

**재생 모드.**

| 모드 | 동작 |
|---|---|
| 보통 | 멈추거나 자막을 숨기지 않고 재생합니다 |
| 준비된 듣기 | 각 문장 앞에서 멈추고 번역을 보여 줍니다 |
| 집중 읽기 | 각 문장 앞에서 멈춰 읽게 한 뒤 듣게 합니다 |
| 집중 듣기 | 문장을 말할 때까지 자막을 숨겼다가 멈추고 보여 줍니다 |
| 집중 혼합 | 각 문장 뒤에서 자막을 보이게 둔 채 멈춥니다 |
| 일시정지할 때 표시 | 영상이 일시정지되었을 때만 자막을 보여 줍니다 |
| 1D 집중 | 모르는 단어가 하나뿐인 문장에서 멈춥니다 |
| 사용자 지정 | 멈춤과 가림을 조정할 수 있습니다 |

대사가 없는 장면은 영상 패널에서 빠르게 재생하거나 건너뛸 수 있습니다.

## 자막

### 트랙 선택

**영상과 자막** 패널의 **자막** 탭에서 일본어 트랙과 보조 자막을 고릅니다. 기본적으로 사람이 만든 자막을 자동 자막보다 우선하고, 가져온 자막을 모든 자막보다 우선합니다.

### Claude로 번역

**AI 자막** 패널의 번역 버튼이나 보조 자막 옆의 **Claude로 번역**은 일본어 자막을 보조 언어로 번역합니다. 스페인어, 영어, 포르투갈어, 프랑스어, 독일어를 지원합니다.

- 지금 보고 있는 구간부터 시작하므로 그 부분은 몇 초 안에 준비됩니다.
- 결과는 도착하는 대로 나타납니다.
- 취소해도 번역된 내용은 보존되고, 다시 누르면 빠진 줄만 요청합니다.

### 자동 자막 수정

자동 자막은 동음이의어를 자주 혼동합니다. Claude는 제목과 전체 텍스트를 맥락으로 삼아 묻지 않고 수정합니다.

- 자동 트랙에서는 기본으로 켜져 있으며 패널에서 끌 수 있습니다.
- 명백한 오류가 있는 부분만 바꿉니다. Claude가 인식 과정에서 지어낸 것으로 판단한 줄은 삭제합니다.
- 수정 내용은 저장되어 다시 요청하지 않습니다.
- 탐색기는 수정된 줄을 표시하고 원문을 볼 수 있게 합니다.

### 다른 언어에서 일본어 만들기

다른 언어 자막만 있을 때 Claude가 일본어로 옮길 수 있습니다. 번역의 번역이므로 들리는 내용과 완전히 일치하지는 않습니다. 일본어 자막 파일이 있다면 언제나 그쪽이 낫습니다.

### 가져오기와 내보내기

각 트랙에는 **가져오기**와 **SRT 내보내기** 버튼이 있습니다. 파일을 영상 위로 끌어 놓아도 됩니다. SRT, VTT, ASS, SSA, TTML, DFXP를 지원합니다.

- 가져온 자막은 해당 제목에 저장되고 사이트의 트랙보다 우선합니다.
- 내보내기에는 동기화 조정이 포함됩니다.

### Netflix 지역

Netflix 작품의 일본어 자막은 시청할 때 식별자와 함께 저장됩니다. 다른 지역 카탈로그에 같은 작품이 그 트랙 없이 제공되면, Kotonoha는 이를 ‘일본어 (저장됨)’으로 보여 주고 그 지역에서 제공하는 자막을 보조 자막으로 씁니다. SRT로 내보낸 뒤 파일을 가져오면 같은 일을 직접 할 수 있습니다.

### 동기화

**동기화** 탭에서 트랙별 오프셋을 조정합니다. 탐색기에서 **동기화: 지금 이 줄이 재생 중입니다**를 눌러도 됩니다. 표시 하나로 오프셋을, 둘로 속도까지 바로잡습니다. 오프셋은 `Alt+I`와 `Alt+O`로 조정합니다.

## Whisper 전사

Whisper는 영상에 자막이 없을 때 일본어 자막을 만듭니다. WebGPU로 그래픽 카드에서 실행되며 오디오는 컴퓨터 밖으로 나가지 않습니다. 처음에는 모델을 내려받아 브라우저에 보관합니다. Netflix에서는 제공하지 않습니다. 작품 대부분에 자막이 있기 때문입니다.

| 출처 | 필요한 것 | 속도 |
|---|---|---|
| 앱 플레이어의 내 파일 | 없음 | 영상 30분당 약 5분 |
| 인터넷 영상, 로컬 도우미 사용 | 도우미 설치 | 영상 30분당 약 5분, 다운로드 시간 별도 |
| 인터넷 영상, 도우미 없음 | `Alt+Shift+M` 또는 확장 프로그램 메뉴의 스위치로 오디오 캡처 켜기 | 실시간, 몇 초 지연 |

**모델.**

| 모델 | 다운로드 | 용도 |
|---|---|---|
| 자동 | | 기본값. 일본어 말소리에는 Haas-ja, 영어 말소리에는 Parakeet, 노래에는 Whisper Turbo |
| Haas-ja | 1.3GB | 일본어 전용. 말소리에 가장 정확하고 빠르며, 배경 음악이 있어도 마찬가지이고 문장 부호도 넣습니다 |
| Parakeet | 1.3GB | 영어 전용. 말소리에 가장 정확하고 빠르며, 배경 음악이 있어도 마찬가지이고 문장 부호와 가장 정확한 시간을 넣습니다 |
| Whisper Turbo | 1.5GB | 노래에 가장 좋습니다 |
| Whisper Turbo 라이트 | 564MB | 정확도가 약간 낮고 비디오 메모리를 덜 씁니다 |
| Whisper Base | 165MB | 고성능 GPU가 없는 컴퓨터용입니다 |

자동 모드에서는 가사를 붙여 넣었거나, 사이트가 음악으로 분류했거나, 제목에 「MV」나 「歌ってみた」처럼 적혀 있으면 노래로 봅니다. 일본어 말소리에서 Haas-ja의 오류율은 3%로 Whisper Turbo의 9%보다 낮고, 30분을 약 1분에 전사합니다. Whisper는 약 5분이 걸립니다. 노래에서는 부르는 내용의 일부만 적기 때문에 Whisper Turbo가 더 좋습니다. 영어에서는 Parakeet가 같은 역할을 합니다. 오류율은 6.8%로 Whisper Turbo의 9.6%보다 낮고, 시간은 세 배 더 정확합니다. 전사하는 동안 패널에 어떤 모델이 작업 중인지 표시됩니다.

모델은 브라우저에 저장되며 다시 다운로드하지 않습니다. 매번 디스크에서 읽으며, 몇 초 걸릴 수 있습니다. **설정, 음성 전사, 저장된 모델**에서 각 모델이 차지하는 용량을 확인하고 삭제할 수 있습니다. 확장 프로그램을 제거해도 함께 삭제됩니다.

**강도.** 그래픽 카드가 일하는 시간의 비율을 정합니다. 나머지 시간에는 쉬며, 다른 앱이 카드를 사용 중이면 쉬는 시간이 저절로 늘어납니다.

| 강도 | 점유율 | 영상 30분 |
|---|---|---|
| 자동 | 컴퓨터 사용 중 75%, 2분간 미사용 후 90% | 약 5분 |
| 부드러움 | 30% | 약 12분 |
| 빠름 | 90% | 약 4분 |

전사 중에 일시정지하면 카드를 즉시 비우고 같은 지점에서 다시 시작할 수 있습니다. 그래픽 드라이버가 다시 시작되면 Whisper는 20초 기다린 뒤 모델을 다시 불러와 최저 강도로 계속합니다. 두 번째 실패에서는 멈추고, 전사한 내용은 저장됩니다.

### 노래 가사

Whisper는 시간은 잘 맞히지만 노래에서는 많은 단어를 잘못 듣습니다. 영상 댓글 등에 가사가 올라와 있다면 **AI 자막** 패널의 **노래 가사**에 붙여넣을 수 있으며, Claude가 그 시간에 맞춰 배치합니다.

- Claude는 어떤 소절이 전사의 어느 줄에서 들리는지만 알려 줍니다. 단어는 가사 그대로이고, 시간은 Whisper에서 가져옵니다.
- 전사 전이나 전사 중에 가사를 붙여넣으면 끝날 때 자동으로 맞춰지며, Whisper가 들은 내용을 수정하거나 검토하는 데 비용이 들지 않습니다. 영상에 이미 자막 트랙이 있으면 **가사를 이 시간에 맞추기**로 그 트랙을 시간 기준으로 쓸 수도 있습니다.
- 한 번만 적힌 후렴은 들리는 곳마다 배치됩니다. 구간 표시, 로마자, 번역처럼 부르지 않는 내용은 무시합니다.
- Whisper가 듣지 못한 소절은 시간을 추정하며, 마지막 알림에 그 수가 표시됩니다. 이때는 탐색기의 **동기화: 지금 이 줄이 재생 중입니다**로 미세 조정할 수 있습니다.
- 결과는 그 영상에 저장되는 또 하나의 트랙 ‘일본어 (가사)’입니다. 원래 전사도 그대로 남습니다. 노래 한 곡에 Claude 요청은 한 번이며, 같은 가사로 다시 맞춰도 비용이 들지 않습니다.
- 로컬 도우미 없이 인터넷 영상을 쓰면 Whisper가 노래 전체를 들어야 합니다. 영상이 끝나면 전사가 저절로 멈추고 가사가 맞춰집니다.

### 로컬 도우미

확장 프로그램은 영상의 오디오를 스스로 내려받을 수 없습니다. 도우미는 [yt-dlp](https://github.com/yt-dlp/yt-dlp)와 FFmpeg로 이 일을 하는 작은 로컬 프로그램입니다. Python이 필요하고, 설치 프로그램이 없는 경우 yt-dlp를 추가합니다. 프로젝트 폴더에서 한 번만 설치합니다.

```bash
powershell -ExecutionPolicy Bypass -File herramientas\ayudante\instalar.ps1
```

그런 다음 `edge://extensions` 또는 `chrome://extensions`에서 확장 프로그램을 다시 로드해야 합니다. 상태는 **설정, 전사**에서 확인합니다.

| 항목 | 동작 |
|---|---|
| 범위 | 확장 프로그램만 호출할 수 있고 http 또는 https 주소만 받습니다 |
| 등록 | 관리자 권한 없이 `HKCU`에 사용자별 키를 추가합니다 |
| 파일 | 끝나거나 취소되면 삭제되는 임시 폴더를 사용합니다 |
| 식별자 | 확장 프로그램을 다른 폴더에서 로드하면 식별자가 바뀝니다. `-Extension`으로 지정하며, 확장 프로그램 페이지에 표시됩니다 |
| 제거 | 같은 명령에 `-Quitar` |

비공개이거나 연령 제한이 있어 영상을 내려받을 수 없으면, 재생하면서 전사하도록 알림에서 제안합니다.

## 카드

| 단축키 | 동작 |
|---|---|
| `Q`, `Alt+Q` | 현재 단어와 문장으로 카드를 만듭니다 |
| `E` | 마우스 아래의 단어, 선택 영역 또는 이미지를 카드 제작기로 보냅니다 |

카드는 AnkiConnect로 Anki에 보내거나(자신의 노트 유형 또는 확장 프로그램이 만든 유형 사용) FSRS를 쓰는 내장 복습인 **메모리**에 저장할 수 있습니다. 필드에는 문장, 후리가나, 번역, 정의, 오디오, 이미지, 메모가 있습니다. 오디오 캡처는 `Alt+Shift+M` 또는 확장 프로그램 메뉴의 스위치로 켭니다.

**영상의 오디오와 이미지.** 문장의 오디오를 녹음하려면 영상 탭에서 `Alt+Shift+M` 또는 확장 프로그램 메뉴의 스위치로 캡처를 켜야 합니다. 캡처는 그 탭에서만 작동합니다. 다른 탭에서 켜져 있으면 마이크 아이콘이 꺼진 것으로 표시되고 카드는 오디오 없이 만들어집니다. 카드를 만들 때 그 줄을 보통 속도로 다시 재생하며 녹음하고, 그 뒤 영상은 원래 위치로 돌아갑니다. 이미지에는 인터페이스가 전혀 포함되지 않습니다. Netflix처럼 DRM이 있는 사이트에서는 브라우저가 화면을 검게 전달합니다. 이때 카드에는 에피소드의 공식 이미지가 들어가고, 사이트가 제공하지 않으면 이미지가 없습니다. 보호된 사이트는 소리도 전달하지 않을 수 있습니다. 카드는 오디오 없이 만들어지며, 한 영상에서 무음 문장이 두 번 연속되면 녹음을 위해 다시 재생하지 않습니다.

## 웹 페이지, 리더, 서재

**웹 페이지.** 일본어 글이 있는 어떤 페이지에서든 리더가 단어에 아는 정도에 따라 밑줄을 긋고 후리가나를 답니다. 단어를 클릭하면 단어 패널이 열립니다. 링크와 버튼에서는 클릭이 그대로 사이트 동작이고, 마우스를 올려 두면 패널이 열리며 `Shift`를 누르면 바로 열립니다. 끌면 그대로 텍스트가 선택되고, 패널이 열려 있으면 `1`~`4`와 `Q`를 쓸 수 있습니다.

오른쪽 가장자리 버튼으로 페이지를 떠나지 않고 색상과 후리가나를 조정하며, 확장 프로그램 메뉴에서 리더를 켜고 끕니다. 후리가나에는 네 가지 모드가 있습니다. 모든 단어, 새 단어만, 마우스를 올릴 때, 표시 안 함입니다. **설정, 페이지 리더**에서 패널이 항상 마우스를 올릴 때 열리게 하거나 링크 클릭으로도 찾아보게 할 수 있습니다.

이 모든 것은 페이지 내용에 아무것도 추가하지 않습니다. 색상은 CSS Custom Highlight API를 쓰고 읽는 법은 별도 레이어에 있으므로, 선택, 복사, 검색은 그대로이며 React 등으로 만든 앱을 방해하지 않습니다. 채팅 대화처럼 상자 안에서 스크롤되는 내용에서도 작동합니다. 후리가나는 글과 함께 움직이고 입력창 아래로 지나갑니다. 입력란, 중국어나 한국어 텍스트에는 작동하지 않습니다.

**줄 간격 넓히기.** 줄 사이가 좁은 페이지가 많아 후리가나가 윗줄과 겹칠 수 있습니다. 그런 곳에서는 그 글의 줄 간격을 필요한 만큼만 넓히며, 이것이 리더가 페이지에서 움직일 수 있는 유일한 부분입니다. 버튼과 메뉴에서는 하지 않고, 글이 고정 높이 상자를 벗어나게 되는 곳에서도 하지 않습니다. 그런 곳에 공간이 전혀 없으면 후리가나는 마우스를 올릴 때까지 미룹니다. 가장자리 버튼의 **줄 간격 넓히기** 스위치로 끌 수 있으며, 그러면 레이아웃은 전혀 움직이지 않습니다.

`Alt+K`, `Alt+U`, `Alt+I`는 선택한 텍스트를 한꺼번에 아는 단어, 모르는 단어, 무시로 표시합니다.

**리더.** 붙여 넣은 모든 텍스트를 자막과 같은 도움 기능으로 보여 줍니다.

**웹 모드.** 앱 창에는 탭이 없어 브라우저의 분할 화면에 들어갈 수 없습니다. 리더의 **웹 모드** 버튼은 사이드바 없이 일반 탭에서 리더를 열고, 확장 프로그램 메뉴의 **이 탭 옆에 리더 열기**는 보고 있는 페이지 바로 옆에 둡니다(Chrome 155 이상). 그 탭에서 **클립보드 따라가기**는 탭이 보이는 동안 어디서든 복사한 일본어를 아래에 덧붙입니다. 확장 프로그램 자체의 페이지이므로 서버가 필요 없고, 오프라인에서 작동하며, 텍스트는 컴퓨터 밖으로 나가지 않습니다.

**서재.** EPUB 책, 텍스트, SRT 자막을 읽던 위치와 함께 저장합니다. 설정한 수준에 맞는 이야기를 Claude로 만들 수도 있습니다.

**로컬 플레이어.** ffmpeg.wasm으로 MKV 내장 자막과 오디오 트랙 선택을 지원하며 내 파일을 재생합니다.

**단어와 평가.** 탐색기는 어휘를 상태별로 나열하고, 수준 평가는 처음에 아는 단어 수를 추정합니다.

## 영어 공부하기

언어는 환영 화면, **설정, 언어와 수준**, 또는 확장 프로그램 메뉴에서 고릅니다. 언어마다 단어, 사전, 카드, 서재, 읽기 설정이 따로 있으며, 다른 언어로 돌아가도 모든 것이 그대로 있습니다. 인터페이스, Claude 키, 비용은 공통입니다.

이 안내에서 설명하는 내용은 모두 똑같이 작동하며, 차이는 다음과 같습니다.

| 항목 | 영어 |
|---|---|
| 사전 | 인터페이스 언어의 Wiktionary로, 정의와 짧은 번역의 두 부분입니다. 인터페이스가 영어이면 영영 사전을 제안하며, 다운로드 약 110MB, 저장 공간 약 220MB입니다 |
| 발음 | 단어 패널에 미국식과 영국식 IPA가 표시됩니다. 단어 위 표시는 처음에 꺼져 있으며 **표시** 패널에서 켭니다. 어느 쪽을 쓸지는 **설정, 언어와 수준**에서 고릅니다 |
| 악센트 색 | 강세 음절을 나타냅니다. 첫 음절, 가운데 음절, 마지막 음절입니다. 이것도 처음에는 꺼져 있습니다 |
| 형태 | 패널이 각 형태가 어떤 단어에서 왔는지 알려 줍니다. *went*는 *go*를, *didn't*는 *do*를 엽니다 |
| 구동사 | 떨어져 있어도 패널이 찾습니다. *picked it up*에서는 *pick up*이 나타납니다. 관용 표현도 마찬가지입니다 |
| 문법 | A1부터 C2까지의 문법 항목을 같은 방식으로 Claude가 확인합니다 |
| 페이지 리더 | 영어는 거의 모든 페이지에 있으므로 처음에는 꺼져 있습니다. 확장 프로그램 메뉴나 **설정, 페이지 리더**에서 켭니다 |
| 획순과 읽는 법 수정 | 제공하지 않습니다 |

## Claude 비용

홈 화면의 **Claude 비용** 카드에는 설정에 입력한 크레딧 대비 이번 달 비용, 일별·모델별 차트, 작업별 내역, 요청별 토큰 기록이 표시됩니다. 비용은 API가 보고한 토큰과 공개 가격으로 계산하며, 이 브라우저의 이 확장 프로그램에서 보낸 요청만 집계합니다.

영상당 가장 많이 드는 것은 자동 자막 수정이고, 그다음이 번역과 읽는 법·뜻·문법 검토입니다. 검토는 재생 위치 앞쪽 몇 분을 다루며 재생에 따라 진행되고, 검토한 내용은 저장됩니다. **자막 생성**에서 끄거나 **영상 전체 검토**로 영상 전체를 요청할 수 있습니다. [비용 연구](costs.md)에 영상별·월별 측정값이 있습니다.

단어 요청의 사용량을 정하는 설정은 세 가지입니다.

| 설정 | 위치 | 기본값 | 효과 |
|---|---|---|---|
| 단어를 열 때 뜻 묻기 | 설정, Claude | 꺼짐 | 새 단어를 열 때마다 요청이 됩니다 |
| 전체 대본을 맥락으로 | 설정, Claude | 꺼짐 | 이름과 지칭에 맥락을 더 주지만 요청당 비용이 늘어납니다 |
| 첫 탭 | 설정, 사전 | 사전만 | Claude 탭을 고르면 단어를 열 때마다 요청합니다 |

## 데이터와 백업

모든 데이터는 브라우저의 IndexedDB에 저장됩니다. **설정, 내 데이터**에서 사용한 모든 언어의 단어, 카드, 서재, 생성된 자막, 수정 내용과 설정, 비용 기록이 담긴 파일 하나를 내보내고 가져올 수 있습니다. Claude 키와 사전은 포함되지 않습니다. 버전 0.4.0 이전의 백업은 일본어로 복원됩니다.

| ‘영상을 들으려면 오디오 캡처를 켜야 합니다’ | Chrome은 탭 캡처에 사용자 동작을 요구합니다. 영상 탭에서 `Alt+Shift+M` 또는 확장 프로그램 메뉴의 스위치로 해결합니다 |
| `Alt+Shift+M`, `Alt+Shift+K`, `Alt+Q` 같은 단축키가 반응하지 않습니다 | Chrome은 다른 확장 프로그램이 이미 가진 키를 비활성화 상태여도 할당하지 않으며 알려 주지도 않습니다. 확장 프로그램 메뉴와 단축키 패널에 실제 키가 표시되고, `chrome://extensions/shortcuts`에서 바꿀 수 있습니다 |
| `Alt+R` 또는 `Alt+Z`가 Radeon Software를 엽니다 | AMD 그래픽 컴퓨터에서 그 앱이 쓰는 단축키입니다. Kotonoha는 `Alt+Shift+M`과 `Alt+V`를 씁니다 |
| 인터페이스에 흐림 효과가 없습니다 | 하드웨어 가속을 끄면 영상 위 흐림 효과가 프레임을 잃으므로, 확장 프로그램이 더 불투명한 배경으로 대체합니다 |
| Whisper가 매우 느립니다 | 브라우저가 GPU에 접근하지 못합니다. 브라우저 설정의 하드웨어 가속을 확인해야 합니다 |
| 도우미가 설치된 것으로 나타나지 않습니다 | 설치 프로그램을 실행한 뒤 확장 프로그램을 다시 로드해야 합니다. 다른 폴더에서 로드했다면 `-Extension`으로 식별자를 지정해야 합니다 |
| 영상을 내려받을 수 없습니다 | 연령 제한, 비공개, 유료 영상은 yt-dlp가 가져올 수 없습니다. 재생하면서 전사할 수 있습니다 |
| YouTube 자막이 비어 있습니다 | 요청은 플레이어가 서명합니다. 영상을 몇 초 재생하면 됩니다 |
| Anki가 연결되지 않습니다 | AnkiConnect가 있는 Anki가 열려 있어야 하고, 그 구성에서 확장 프로그램의 출처를 허용해야 합니다. 확장 프로그램이 처음에 권한을 요청합니다 |
