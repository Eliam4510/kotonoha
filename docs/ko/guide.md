## 시작하기

처음 사용할 때 환영 화면이 열려 언어, 공부할 언어, 수준을 묻고, 사전 설치, Claude 키 추가, 카드 저장 위치 선택을 제안합니다. 건너뛸 수 있으며 **설정, 외관**에서 다시 볼 수 있습니다. 나머지는 모두 `Alt+Shift+K`로 여는 확장 프로그램 창의 **설정**에서 구성합니다.

| 단계 | 위치 | 용도 |
|---|---|---|
| 사전 | 설정, 사전 | 스페인어, 영어 또는 독일어 JMdict, Kanjium의 고저 악센트, JPDB의 빈도. 한 번 내려받아 브라우저에 보관합니다 |
| Claude API 키 | 설정, Claude | 설명, 읽는 법 검토, 번역, 수정. 브라우저에만 저장됩니다 |
| 다른 AI 제공업체 | 설정, 다른 AI 제공업체 | 자신의 키를 쓰는 OpenRouter, DeepSeek, OpenAI, 또는 이 컴퓨터의 LM Studio와 Ollama를 고른 작업에 사용. Claude가 계속 기본 |
| 언어와 수준 | 설정, 언어와 수준 | 인터페이스 언어와 별도로 설정하는 설명과 번역 언어. 수준은 설명 방식을 조정하고 처음에 후리가나를 얼마나 보여 줄지 정합니다 |
| 공부하는 언어 | **홈**과 사이드바, 설정, 언어와 수준, 확장 프로그램 메뉴, 또는 영상 위의 **영상 설정, 자막** | 일본어, 영어 또는 독일어. 언어마다 단어, 사전, 카드, 설정을 따로 저장합니다 |
| Anki | 설정, 카드와 Anki | 선택 사항. AnkiConnect 부가 기능이 설치된 Anki를 열어 두어야 합니다 |

확장 프로그램은 Claude 키 없이도 작동합니다. 자막, 사전, 후리가나, 색상, 카드, Whisper에는 키가 필요하지 않습니다.

**다른 AI 제공업체.** **설정**의 ‘다른 AI 제공업체’에서 키를 넣어 OpenRouter, DeepSeek, OpenAI를 추가하거나, 키 없이 이 컴퓨터의 LM Studio와 Ollama를 추가합니다. **모델 보기**는 각 제공업체의 모델을 보여 주고, **연결 테스트**는 최소한의 요청을 보냅니다. 그다음 **작업별 모델과 노력 수준**에서 작업마다 그 모델을 쓸 수 있습니다. 구조가 있는 답은 JSON 스키마로 요청하고, DeepSeek처럼 지원하지 않으면 스키마를 지시문에 넣어 JSON 모드로 요청합니다. 답의 토큰을 그만큼 허용하지 않으면 더 적게 요청합니다. 지출은 제공업체가 알려 주는 비용으로 기록되며(OpenRouter는 알려 줍니다), 이 컴퓨터의 모델은 0으로 계산됩니다. 키는 Claude 키처럼 따로 저장되어 웹페이지에 절대 전달되지 않습니다. 지시문은 Claude에 맞춰져 있어, 다른 모델에서는 답이 더 나쁠 수 있습니다. Ollama는 `OLLAMA_ORIGINS=chrome-extension://*`로 실행해야 확장 프로그램에 응답합니다.

### 맞춤 설정

| 옵션 | 위치 | 용도 |
|---|---|---|
| 로마자 읽는 법 | 설정, 언어와 수준 | 아직 가나를 읽지 못하는 사람을 위한 것입니다. 자막, 단어 패널, 페이지에 적용됩니다 |
| 단어 색상 | 설정, 외관 | 세 가지 팔레트: 기본, 빨강과 초록 없이 구별되는 색각 이상용, 고대비 |
| 단축키 | 설정, 키보드 단축키 | 영상 위 단축키는 여기서 바꿉니다. 오디오 캡처처럼 브라우저가 쓰는 단축키는 브라우저의 단축키 페이지에서 바꿉니다 |
| 비용 한도 | 설정, Claude | 한도에 도달하면 다음 달까지 Claude를 사용하지 않습니다 |
| 리더를 쓰지 않는 사이트 | 설정, 페이지 리더 또는 페이지 가장자리의 버튼 | 방해가 되는 곳에서만 끕니다 |

## 영상 위 화면

일본어 자막이 있는 영상을 열면 위쪽에 떠 있는 바가 나타납니다. 예상 이해도, 추천 문장, 아는 단어, 재생 모드를 보여 줍니다. 저절로 숨겨지고, 마우스를 위쪽 가장자리에 멈추면 다시 나타나며, 마우스가 근처에 있는 동안 유지됩니다.

**자막.** 각 단어에는 후리가나, 고저 악센트에 따른 색상, 상태에 따른 밑줄이 표시됩니다. 상태는 모르는 단어, 추적, 아는 단어, 무시입니다. 인식된 문법 포인트는 라벨로 표시됩니다.

**자막 옮기기.** 단어 위를 포함해 어느 지점에서든 끌어서 원하는 높이와 위치로 옮길 수 있습니다. 위치는 모든 영상에 적용되고 영상 크기에 비례해 유지되며, 극장 모드에서도 마찬가지입니다. 배경을 두 번 클릭하거나 표시 설정에서 **제자리로**를 누르면 되돌아갑니다.

**단어 패널.** 단어에 마우스를 올리면 Claude에 아무 요청도 보내지 않고 단어 패널이 열립니다. 정의, 빈도, 오디오, 이미지, 예문, 획순과 Jisho, JapanDict, Weblio, Goo, Kotobank, Wiktionary, Forvo, Massif 링크가 있습니다. JapanDict 링크는 동형이의어 목록이 아니라 JMdict의 정확한 항목을 엽니다.

**이 문장에서.** Claude 키가 있으면 **이 문장에서는 무슨 뜻인가요?** 버튼이 그 맥락에서의 뜻을 알려 주고 비유적이거나 시적인 용법을 표시합니다. Claude는 문장 주변 40줄과 번역을 받습니다. **설명**, **분석**, **번역** 탭도 같은 방식으로, 누를 때 요청합니다. 모든 답변이 저장되므로 그 문장의 그 단어로 돌아와도 비용이 들지 않으며, 패널에 **저장됨, 비용 없음**이 표시됩니다. **더 알아보기** 버튼은 Opus 5.5로 다시 요청합니다.

**이미지로 공유.** 단어 패널에서 빈도 옆에 있는 **이미지로 공유** 버튼은 단어와 후리가나, 악센트, 이 문장에서의 뜻(Claude에게 묻지 않았다면 사전의 뜻), 단어를 강조한 원래 문장, 동영상이나 책의 제목을 담은 카드를 그려 클립보드에 복사합니다. 채팅에서 Ctrl+V로 붙여 넣으면 됩니다. **이 문장의 문법**의 각 항목에도 같은 버튼이 있어, 문형과 수준, 뜻, Claude 설명의 첫 항목을 담은 카드를 만듭니다. 카드는 테마처럼 **먹색**과 **종이** 두 가지이며 마지막으로 고른 스타일을 기억합니다. **이미지 저장**으로 PNG 파일로 내려받을 수 있습니다. 카드는 브라우저에서 그려지며 아무것도 보내지 않습니다.

**획순.** 단어 패널의 **획순** 탭은 단어에 있는 각 한자를 쓰는 법을 보여 줍니다. 획이 번호와 함께 하나씩 그려지며 반복됩니다. 일시정지, 한 획씩 넘기기, 속도 변경이 가능합니다. 데이터는 [KanjiVG](https://kanjivg.tagaini.net)에서 가져오며, 한자마다 처음 한 번 내려받아 브라우저에 보관합니다. 아래의 **이 한자로 이미 아는 단어**는 한자마다 그 한자가 들어가고 이미 아는 단어나 학습 중으로 표시한 단어를 모아 보여 주며(冷蔵庫: 冷たい, 車庫, 金庫), 아는 단어가 먼저 나옵니다. 이미 아는 것을 통해 새 한자를 기억할 수 있습니다.

**자막 탐색기.** `G`를 누르면 모든 줄, 필터, 표시, 다중 선택이 있는 사이드 패널이 열립니다. 줄 합치기, 여러 카드 만들기, 동기화도 할 수 있습니다.

**재생 모드.**

| 모드 | 동작 |
|---|---|
| 보통 | 멈추거나 자막을 숨기지 않고 재생합니다 |
| 준비된 듣기 | 각 문장 앞에서 멈추고 번역을 보여 줍니다 |
| 집중 읽기 | 각 문장 앞에서 멈춰 읽게 한 뒤 듣게 합니다 |
| 집중 듣기 | 문장을 말할 때까지 자막을 숨겼다가 멈추고 보여 줍니다 |
| 받아쓰기 | 자막을 숨기고 문장이 끝날 때마다 멈춰 들은 내용을 쓰게 한 뒤 맞힌 부분을 표시 |
| 집중 혼합 | 각 문장 뒤에서 자막을 보이게 둔 채 멈춥니다 |
| 일시정지할 때 표시 | 영상이 일시정지되었을 때만 자막을 보여 줍니다 |
| 1D 집중 | 모르는 단어가 하나뿐인 문장에서 멈춥니다 |
| 사용자 지정 | 멈춤과 가림을 조정할 수 있습니다 |

**받아쓰기와 내 목소리로 따라 하기.** **받아쓰기** 모드에서는 문장이 끝날 때마다 동영상이 멈추고, 자막 자리에 들은 내용을 씁니다. **확인**을 누르면 맞힌 단어는 초록색, 절반은 노란색, 놓친 단어는 밑줄로 표시하고 점수를 보여 줍니다. 일본어는 읽는 법으로 비교하므로 가나로 써도 되고, 한자가 있는 단어에 쓴 내용과 맞는 다른 사전 읽기(後를 あと로)가 있으면 맞은 것으로 칩니다. **다시 듣기**는 문장을 반복하고, **계속** 또는 Enter로 이어집니다. 결과의 **내 목소리로 따라 하기**나 자막 위에서 `P` 키를 누르면 Kotonoha 창에서 그 문장으로 악센트 연습을 엽니다. 동영상에서 `S`로 듣고 똑같이 말한 뒤 억양을 비교합니다.

대사가 없는 장면은 영상 패널에서 빠르게 재생하거나 건너뛸 수 있습니다.

## 자막

### 트랙 선택

**영상과 자막** 패널의 **자막** 탭에서 일본어 트랙과 보조 자막을 고릅니다. 기본적으로 사람이 만든 자막을 자동 자막보다 우선하고, 가져온 자막을 모든 자막보다 우선합니다.

### Claude로 번역

**AI 자막** 패널의 번역 버튼이나 보조 자막 옆의 **Claude로 번역**은 일본어 자막을 보조 언어로 번역합니다. 스페인어, 영어, 포르투갈어, 프랑스어, 독일어를 지원합니다.

- 지금 보고 있는 구간부터 시작하므로 그 부분은 몇 초 안에 준비됩니다.
- 결과는 도착하는 대로 나타납니다.
- 취소해도 번역된 내용은 보존되고, 다시 누르면 빠진 줄만 요청합니다.

### 자동 자막 수정

자동 자막은 동음이의어를 자주 혼동합니다. Claude는 제목과 전체 텍스트를 맥락으로 삼아 묻지 않고 수정합니다.

- 자동 트랙에서는 기본으로 켜져 있으며 패널에서 끌 수 있습니다.
- 명백한 오류가 있는 부분만 바꿉니다. Claude가 인식 과정에서 지어낸 것으로 판단한 줄은 삭제합니다.
- 수정 내용은 저장되어 다시 요청하지 않습니다.
- 탐색기는 수정된 줄을 표시하고 원문을 볼 수 있게 합니다.

### 다른 언어에서 일본어 만들기

다른 언어 자막만 있을 때 Claude가 일본어로 옮길 수 있습니다. 번역의 번역이므로 들리는 내용과 완전히 일치하지는 않습니다. 일본어 자막 파일이 있다면 언제나 그쪽이 낫습니다.

### 가져오기와 내보내기

각 트랙에는 **가져오기**와 **SRT 내보내기** 버튼이 있습니다. 파일을 영상 위로 끌어 놓아도 됩니다. SRT, VTT, ASS, SSA, TTML, DFXP를 지원합니다.

- 가져온 자막은 해당 제목에 저장되고 사이트의 트랙보다 우선합니다.
- 내보내기에는 동기화 조정이 포함됩니다.

### Netflix 지역

Netflix 작품의 일본어 자막은 시청할 때 식별자와 함께 저장됩니다. 다른 지역 카탈로그에 같은 작품이 그 트랙 없이 제공되면, Kotonoha는 이를 ‘일본어 (저장됨)’으로 보여 주고 그 지역에서 제공하는 자막을 보조 자막으로 씁니다. SRT로 내보낸 뒤 파일을 가져오면 같은 일을 직접 할 수 있습니다.

### 동기화

**동기화** 탭에서 트랙별 오프셋을 조정합니다. 탐색기에서 **동기화: 지금 이 줄이 재생 중입니다**를 눌러도 됩니다. 표시 하나로 오프셋을, 둘로 속도까지 바로잡습니다. 오프셋은 `Alt+I`와 `Alt+O`로 조정합니다.

## Whisper 전사

Whisper는 영상에 자막이 없을 때 일본어 자막을 만듭니다. WebGPU로 그래픽 카드에서 실행되며 오디오는 컴퓨터 밖으로 나가지 않습니다. 처음에는 모델을 내려받아 브라우저에 보관합니다. Netflix에서는 제공하지 않습니다. 작품 대부분에 자막이 있기 때문입니다.

| 출처 | 필요한 것 | 속도 |
|---|---|---|
| 앱 플레이어의 내 파일 | 없음 | 영상 30분당 약 5분 |
| 인터넷 영상, 로컬 도우미 사용 | 도우미 설치 | 영상 30분당 약 5분, 다운로드 시간 별도 |
| 인터넷 영상, 도우미 없음 | `Alt+Shift+M` 또는 확장 프로그램 메뉴의 스위치로 오디오 캡처 켜기 | 실시간, 몇 초 지연 |

**모델.**

| 모델 | 다운로드 | 용도 |
|---|---|---|
| 자동 | | 기본값. 일본어 말소리에는 Haas-ja, 영어와 독일어 말소리에는 Parakeet, 노래에는 Whisper Turbo |
| Haas-ja | 1.3GB | 일본어 전용. 말소리에 가장 정확하고 빠르며, 배경 음악이 있어도 마찬가지이고 문장 부호도 넣습니다 |
| Parakeet | 1.3GB | 영어와 독일어. 말소리에 가장 정확하고 빠르며, 배경 음악이 있어도 마찬가지이고 문장 부호와 가장 정확한 시간을 넣습니다 |
| Whisper Turbo | 1.5GB | 노래에 가장 좋습니다 |
| Whisper Turbo 라이트 | 564MB | 정확도가 약간 낮고 비디오 메모리를 덜 씁니다 |
| Whisper Base | 165MB | 고성능 GPU가 없는 컴퓨터용입니다 |

자동 모드에서는 가사를 붙여 넣었거나, 사이트가 음악으로 분류했거나, 제목에 「MV」나 「歌ってみた」처럼 적혀 있으면 노래로 봅니다. 일본어 말소리에서 Haas-ja의 오류율은 3%로 Whisper Turbo의 9%보다 낮고, 30분을 약 1분에 전사합니다. Whisper는 약 5분이 걸립니다. 노래에서는 부르는 내용의 일부만 적기 때문에 Whisper Turbo가 더 좋습니다. 영어에서는 Parakeet가 같은 역할을 합니다. 오류율은 6.8%로 Whisper Turbo의 9.6%보다 낮고, 시간은 세 배 더 정확합니다. 전사하는 동안 패널에 어떤 모델이 작업 중인지 표시됩니다.

모델은 브라우저에 저장되며 다시 다운로드하지 않습니다. 매번 디스크에서 읽으며, 몇 초 걸릴 수 있습니다. **설정, 음성 전사, 저장된 모델**에서 각 모델이 차지하는 용량을 확인하고 삭제할 수 있습니다. 확장 프로그램을 제거해도 함께 삭제됩니다.

**강도.** 그래픽 카드가 일하는 시간의 비율을 정합니다. 나머지 시간에는 쉬며, 다른 앱이 카드를 사용 중이면 쉬는 시간이 저절로 늘어납니다.

| 강도 | 점유율 | 영상 30분 |
|---|---|---|
| 자동 | 컴퓨터 사용 중 75%, 2분간 미사용 후 90% | 약 5분 |
| 부드러움 | 30% | 약 12분 |
| 빠름 | 90% | 약 4분 |

전사 중에 일시정지하면 카드를 즉시 비우고 같은 지점에서 다시 시작할 수 있습니다. 그래픽 드라이버가 다시 시작되면 Whisper는 20초 기다린 뒤 모델을 다시 불러와 최저 강도로 계속합니다. 두 번째 실패에서는 멈추고, 전사한 내용은 저장됩니다.

### 노래 가사

Whisper는 시간은 잘 맞히지만 노래에서는 많은 단어를 잘못 듣습니다. 영상 댓글 등에 가사가 올라와 있다면 **AI 자막** 패널의 **노래 가사**에 붙여넣을 수 있으며, Claude가 그 시간에 맞춰 배치합니다.

- Claude는 어떤 소절이 전사의 어느 줄에서 들리는지만 알려 줍니다. 단어는 가사 그대로이고, 시간은 Whisper에서 가져옵니다.
- 전사 전이나 전사 중에 가사를 붙여넣으면 끝날 때 자동으로 맞춰지며, Whisper가 들은 내용을 수정하거나 검토하는 데 비용이 들지 않습니다. 영상에 이미 자막 트랙이 있으면 **가사를 이 시간에 맞추기**로 그 트랙을 시간 기준으로 쓸 수도 있습니다.
- 한 번만 적힌 후렴은 들리는 곳마다 배치됩니다. 구간 표시, 로마자, 번역처럼 부르지 않는 내용은 무시합니다.
- Whisper가 듣지 못한 소절은 시간을 추정하며, 마지막 알림에 그 수가 표시됩니다. 이때는 탐색기의 **동기화: 지금 이 줄이 재생 중입니다**로 미세 조정할 수 있습니다.
- 결과는 그 영상에 저장되는 또 하나의 트랙 ‘일본어 (가사)’입니다. 원래 전사도 그대로 남습니다. 노래 한 곡에 Claude 요청은 한 번이며, 같은 가사로 다시 맞춰도 비용이 들지 않습니다.
- 로컬 도우미 없이 인터넷 영상을 쓰면 Whisper가 노래 전체를 들어야 합니다. 영상이 끝나면 전사가 저절로 멈추고 가사가 맞춰집니다.

### 로컬 도우미

확장 프로그램은 영상의 오디오를 스스로 내려받을 수 없습니다. 도우미는 Windows에 기본으로 들어 있는 PowerShell로 만든 작은 로컬 프로그램이라, Python이나 FFmpeg를 설치할 필요가 없습니다. [yt-dlp](https://github.com/yt-dlp/yt-dlp)로 오디오를 내려받고, 확장 프로그램 업데이트도 합니다([데이터와 백업](#데이터와-백업)의 **새 버전** 참고). 최신 버전 페이지에서 `kotonoha-X.Y.Z-ayudante.zip`을 내려받아 아무 폴더에나 압축을 풀고 `Instalar.cmd`를 두 번 클릭합니다. 설치 프로그램은:

- 도우미를 `%LOCALAPPDATA%\Kotonoha\ayudante`에 복사하므로, 압축을 푼 폴더는 그 뒤로 필요 없습니다.
- yt-dlp와, yt-dlp가 YouTube 확인 문제를 푸는 데 쓰는 QuickJS를 GitHub의 공식 페이지에서 내려받고 각각의 SHA-256을 확인합니다.
- Chrome, Edge, Brave, Chromium에서 Kotonoha를 찾아, 찾은 사본마다 도우미를 등록합니다.
- 하나도 찾지 못하면 확장 프로그램도 고정 식별자로 설치하겠다고 제안하고, 불러오는 방법을 알려 줍니다.

상태는 **설정, 전사**에서 확인합니다. 설치 프로그램이 사본을 찾지 못하면, 설정에 그 식별자가 들어간 명령이 나오며 도우미 폴더에서 실행하면 됩니다:

```bash
powershell -ExecutionPolicy Bypass -File instalar.ps1 -Extension EXTENSION_ID
```

| 항목 | 동작 |
|---|---|
| 범위 | 확장 프로그램만 호출할 수 있고 http 또는 https 주소만 받습니다 |
| 등록 | 관리자 권한 없이 `HKCU`에 사용자별 키를 추가합니다 |
| 변환 | 컴퓨터에 FFmpeg가 있으면 도우미가 오디오를 변환합니다. 없으면 확장 프로그램이 자체 FFmpeg로 변환하며, 조금 더 느립니다 |
| yt-dlp | 일주일에 한 번 스스로 업데이트합니다. YouTube는 자주 바뀝니다 |
| 파일 | 끝나거나 취소되면 삭제되는 임시 폴더를 사용합니다 |
| 제거 | `Desinstalar.cmd`를 두 번 클릭합니다. 확장 프로그램과 데이터는 건드리지 않습니다 |

비공개이거나 연령 제한이 있어 영상을 내려받을 수 없으면, 재생하면서 전사하도록 알림에서 제안합니다.

## 카드

| 단축키 | 동작 |
|---|---|
| `Q`, `Alt+Q` | 현재 단어와 문장으로 카드를 만듭니다 |
| `E` | 마우스 아래의 단어, 선택 영역 또는 이미지를 카드 제작기로 보냅니다 |

카드는 AnkiConnect로 Anki에 보내거나(자신의 노트 유형 또는 확장 프로그램이 만든 유형 사용) FSRS를 쓰는 내장 복습인 **메모리**에 저장할 수 있습니다. 필드에는 문장, 후리가나, 번역, 정의, 오디오, 이미지, 메모가 있습니다. 오디오 캡처는 `Alt+Shift+M` 또는 확장 프로그램 메뉴의 스위치로 켭니다.

**영상의 오디오와 이미지.** 문장의 오디오를 녹음하려면 영상 탭에서 `Alt+Shift+M` 또는 확장 프로그램 메뉴의 스위치로 캡처를 켜야 합니다. 캡처는 그 탭에서만 작동합니다. 다른 탭에서 켜져 있으면 마이크 아이콘이 꺼진 것으로 표시되고 카드는 오디오 없이 만들어집니다. 카드를 만들 때 그 줄을 보통 속도로 다시 재생하며 녹음하고, 그 뒤 영상은 원래 위치로 돌아갑니다. 이미지에는 인터페이스가 전혀 포함되지 않습니다. Netflix처럼 DRM이 있는 사이트에서는 브라우저가 화면을 검게 전달합니다. 이때 카드에는 에피소드의 공식 이미지가 들어가고, 사이트가 제공하지 않으면 이미지가 없습니다. 보호된 사이트는 소리도 전달하지 않을 수 있습니다. 카드는 오디오 없이 만들어지며, 한 영상에서 무음 문장이 두 번 연속되면 녹음을 위해 다시 재생하지 않습니다.

## 웹 페이지, 리더, 서재

**웹 페이지.** 일본어 글이 있는 어떤 페이지에서든 리더가 단어에 아는 정도에 따라 밑줄을 긋고 후리가나를 답니다. 단어를 클릭하면 단어 패널이 열립니다. 링크와 버튼에서는 클릭이 그대로 사이트 동작이고, 마우스를 올려 두면 패널이 열리며 `Shift`를 누르면 바로 열립니다. 끌면 그대로 텍스트가 선택되고, 패널이 열려 있으면 `1`~`4`와 `Q`를 쓸 수 있습니다.

오른쪽 가장자리 버튼으로 페이지를 떠나지 않고 색상과 후리가나를 조정하며, 확장 프로그램 메뉴에서 리더를 켜고 끕니다. 후리가나에는 네 가지 모드가 있습니다. 모든 단어, 새 단어만, 마우스를 올릴 때, 표시 안 함입니다. **설정, 페이지 리더**에서 패널이 항상 마우스를 올릴 때 열리게 하거나 링크 클릭으로도 찾아보게 할 수 있습니다.

이 모든 것은 페이지 내용에 아무것도 추가하지 않습니다. 색상은 CSS Custom Highlight API를 쓰고 읽는 법은 별도 레이어에 있으므로, 선택, 복사, 검색은 그대로이며 React 등으로 만든 앱을 방해하지 않습니다. 채팅 대화처럼 상자 안에서 스크롤되는 내용에서도 작동합니다. 후리가나는 글과 함께 움직이고 입력창 아래로 지나갑니다. 입력란, 중국어나 한국어 텍스트에는 작동하지 않습니다.

**줄 간격 넓히기.** 줄 사이가 좁은 페이지가 많아 후리가나가 윗줄과 겹칠 수 있습니다. 그런 곳에서는 그 글의 줄 간격을 필요한 만큼만 넓히며, 이것이 리더가 페이지에서 움직일 수 있는 유일한 부분입니다. 버튼과 메뉴에서는 하지 않고, 글이 고정 높이 상자를 벗어나게 되는 곳에서도 하지 않습니다. 그런 곳에 공간이 전혀 없으면 후리가나는 마우스를 올릴 때까지 미룹니다. 가장자리 버튼의 **줄 간격 넓히기** 스위치로 끌 수 있으며, 그러면 레이아웃은 전혀 움직이지 않습니다.

`Alt+K`, `Alt+U`, `Alt+I`는 선택한 텍스트를 한꺼번에 아는 단어, 모르는 단어, 무시로 표시합니다.

**노트.** 예전의 클립보드입니다. 화면 너비 전체를 쓰는 페이지에서 서식 있는 텍스트를 쓰고 붙여 넣고, 자막과 같은 도움을 받으며 읽을 수 있습니다. 위쪽의 **편집**과 **읽기**로 같은 페이지에서 모드를 바꿉니다. 편집할 때는 블록 종류 선택기로 **본문**, **제목**, **소제목**, **세부 제목**, **코드**를 고르고, 버튼으로 **목록**, **번호 목록**, **인용**, **굵게**를 넣습니다. 익숙한 단축 입력도 됩니다. 줄 맨 앞에 `# `을 쓰면 제목, `- `(일본어에서는 ・도)는 목록, `1. `은 번호 목록, `> `는 인용이고, Tab은 하위 항목, Ctrl+B는 굵게입니다. 웹 페이지에서 붙여 넣은 내용은 구조를 유지하고 그 페이지의 후리가나는 빠지며, Claude 채팅에서 복사한 Markdown도 서식대로 들어옵니다. **정리**는 한 덩어리로 붙여 넣은 텍스트에 단어는 바꾸지 않고 제목, 소제목, 문단, 목록을 붙여 달라고 Claude에게 요청합니다. 단어가 바뀌었다면 알려 주고, Ctrl+Z로 원래대로 돌아갑니다. 쓴 내용은 브라우저에 저절로 저장됩니다. **서재에 저장**을 누르면 서재로 옮겨지고, 그때부터는 그곳에도 저장됩니다. **새 노트**는 이전 노트를 잃지 않고 빈 노트를 시작합니다. 이전 노트가 서재에 없었다면 서재로 갑니다. 서재의 텍스트는 **노트에서 편집**으로 다시 편집할 수 있습니다. 모두 Markdown으로 저장되므로 여전히 텍스트이고, 서재와 백업에서도 똑같이 읽힙니다.

**웹 모드.** 앱 창에는 탭이 없어 브라우저의 분할 화면에 들어갈 수 없습니다. 노트의 **웹 모드** 버튼은 사이드바 없이 일반 탭에서 노트를 열고, 확장 프로그램 메뉴의 **이 탭 옆에 노트 열기**는 보고 있는 페이지 바로 옆에 노트를 둡니다(Chrome 155 이상). 그 탭에서 **클립보드 따라가기**는 탭이 화면에 보이는 동안 어디서든 복사한 공부하는 언어의 내용을 끝에 덧붙입니다. 어떤 페이지에서든 선택한 텍스트의 메뉴에 있는 **선택한 내용을 노트에서 열기**도 끝에 덧붙입니다. 확장 프로그램 자체의 페이지이므로 서버가 필요 없고, 오프라인에서도 작동하며, 텍스트가 컴퓨터를 떠나지 않습니다.

**음성 입력.** 노트의 **음성 입력**은 마이크로 녹음해 말한 내용을 끝에 별도의 문단으로 덧붙이고, 분석과 후리가나를 붙여 보여 줍니다. 녹음하는 동안 시간과 마이크 음량이 보이며, **끝내기**는 녹음을 마치고 **취소**는 버립니다. 전사는 **설정**의 ‘음성 전사’에서 고른 모델로 컴퓨터에서 이루어집니다. 자동일 때 일본어는 Haas-ja, 영어와 독일어는 Parakeet입니다. 말하는 동안 모델을 불러오므로, 녹음을 마치면 전사는 몇 초면 끝납니다. 녹음도 텍스트도 컴퓨터를 떠나지 않습니다. 문단 위에는 다시 들을 수 있도록 녹음이 남고, 서재에 저장할 때 텍스트와 함께 갑니다. 편집할 때 녹음은 ‘음성 입력 녹음’ 블록입니다. 지우면 문단은 남고 녹음은 녹음한 지 일주일이 지나면 삭제됩니다. 처음에는 브라우저가 마이크 사용 권한을 묻습니다. 녹음은 한 번에 최대 10분입니다.

**소리 내어 읽기.** 노트, 서재의 텍스트, 뷰어의 글 보기에서 아래 막대의 **소리 내어 읽기**는 문장 음성(로컬, 신경망, Azure, 브라우저 음성)으로 텍스트를 한 문장씩 읽습니다. 속도 버튼은 0.6×, 0.8×, 1×, 1.2×를 돌아가며 바꾸고, 모드 버튼은 **이어서**, 문장이 끝날 때마다 멈추는 **한 문장씩**, 함께 따라 말할 수 있도록 같은 문장을 잠깐 쉬었다가 되풀이하는 **반복**을 돌아가며 바꿉니다. 둘 다 기억됩니다. 마우스로 텍스트의 아무 부분이나 선택하면 그 부분을 읽어 주는 **듣기**와, 일본어에서는 그 부분으로 고저 악센트 연습을 여는 **연습**이 나타납니다. 한 단어, 반 문장, 여러 문장 모두 됩니다.

**고저 악센트 연습.** 노트, 서재의 텍스트, 뷰어의 글 보기에서 아래 막대의 **연습**은 현재 문장의 연습을 엽니다. **이전 문장**과 **다음 문장**으로 다른 문장으로 넘어갑니다. 각 단어 위에는 악센트가 그려집니다. 모라마다 높거나 낮은 선이며, 악센트 핵 뒤에서 내려갑니다. **문장 듣기**는 키가 있으면 Azure 음성으로, 없으면 브라우저 음성으로 읽어 줍니다. **녹음**은 소리 내어 읽은 문장을 최대 20초까지 녹음합니다. Kotonoha는 녹음의 음높이를 브라우저 안에서 재고, 컴퓨터에서 Haas-ja로 전사해 각 단어가 어디서 소리 나는지 알아냅니다. 그래프는 목소리의 음높이 곡선을 기준 악센트 위에 겹쳐 보여 주며, 단어마다 판정이 붙습니다. **좋음**은 음이 제자리에서 내려간 경우, **확인 필요**는 다른 곳에서 내려가거나 내려가지 않은 경우로, 어디서 내려가야 했고 어디서 내려갔는지 알려 줍니다. **판단 안 함**은 악센트를 알 수 없는 활용형, **인식 안 됨**은 녹음에 단어가 나오지 않은 경우입니다. 한 문장 안에서 단어 사이의 긴 멈춤도 표시합니다. **내 녹음 듣기**는 녹음을 재생하고, **다시 녹음**은 다시 시도합니다. 판정하는 것은 음이 어디서 내려가는가이며, 이것이 악센트를 구별합니다. 처음의 상승은 이어서 말할 때 생략되기도 하므로 세지 않고, 멈춤 앞의 마지막 모라도 문장의 억양을 담으므로 세지 않습니다. 각 단어의 악센트는 ‘고저 악센트(Kanjium)’ 사전에서 가져옵니다. 이 사전이 없으면 핵이 동사와 상관없는 〜ます 정중형만 판단합니다. 참고용입니다. 낭독한 문장은 자동 측정이 항상 정확하지는 않습니다. 녹음도 텍스트도 컴퓨터를 떠나지 않으며, 녹음은 저장되지 않습니다. 음성 모델은 연습을 열 때 불러오며, 연습이 열려 있는 동안 계속 올라가 있습니다. 첫 녹음은 모델을 다 불러올 때까지 기다리고(개발용 컴퓨터에서 약 30초), 그다음부터는 1초도 안 걸려 분석합니다.

**특수 모라.** 연습 패널에서 **っ, ん과 장모음도 확인**을 켜면 Kotonoha가 녹음에서 특수 모라가 빠지거나 더해졌는지도 확인합니다. 들리지 않는 っ(きって를 きて로), ん(かんじ를 かじ로), 짧게 말한 장모음(おばあさん을 おばさん으로), 또는 더해진 모라(おばさん을 おばあさん으로)입니다. **모라** 표시가 붙은 각 알림은 어느 단어인지 알려 주고, 기준 악센트에서 그 모라를 표시합니다. 알림이 없으면 **모라**가 빠지거나 더해진 것이 없다고 알려 줍니다. 듣는 것은 컴퓨터에서 실행되는 일본어 음소 모델 narabas입니다. GPU가 프로세서와 같은 결과를 내면 GPU에서, 아니면 프로세서에서 실행됩니다. 처음에는 작성자의 GitHub 배포에서 1.26 GB를 내려받아 SHA-256으로 확인한 뒤 브라우저에 저장하며, **설정, 음성 전사**의 **저장된 모델**에서 지울 수 있습니다. s, sh, z, j, h, f 앞의 っ는 모델이 표시하지 않으므로 판단하지 않으며, 다르게 말했거나 인식되지 않은 구도 판단하지 않습니다. 단어 끝에서 늘인 모음이나 멈춤도 세지 않습니다. 망설임일 뿐 단어의 오류가 아니기 때문입니다. 합성 음성 두 개로 말한 최소 대립쌍으로 측정한 결과, 빠진 모라 22개 중 17개와 더해진 모라 10개 중 10개를 찾았고, 바르게 말한 문장 24개 중 22개에서는 아무 알림도 내지 않았습니다.

**로컬 음성.** 컴퓨터에서 AivisSpeech나 VOICEVOX가 실행 중이면 Kotonoha는 그 음성으로 일본어 문장을 읽습니다. 소리 내어 읽기, 연습의 **문장 듣기**, 단어 카드, 카드용 오디오에 쓰입니다. **설정**의 ‘음성’에서 **로컬 음성**은 늘 쓰는 포트(AivisSpeech는 10101, VOICEVOX는 50021)에서 찾았는지 알려 주며, **로컬 음성으로 문장 읽기**로 켜고 **음성과 스타일**을 고릅니다. **사전 악센트**를 켜면 읽기 전에 악센트 사전으로 각 단어의 악센트를 바로잡으므로, 본보기 음성이 사전대로 말합니다. 오디오는 캐시에 저장되어 한 번 읽은 문장은 바로 재생됩니다. 프로그램이 꺼져 있으면 키가 있을 때는 Azure로, 없으면 브라우저 음성으로 읽습니다. AivisSpeech는 무료이며 아무것도 컴퓨터를 떠나지 않습니다.

**서재.** 뷰어에서 열리는 EPUB, CBZ, PDF 책과 이미지 폴더, 텍스트, SRT 자막을 읽던 위치, 각 장의 구조와 함께 저장합니다. 설정한 수준에 맞는 이야기를 Claude로 만들 수도 있습니다.

**뷰어.** 만화나 스캔한 책처럼 이미지로 된 EPUB, CBZ, PDF는 PDF 리더처럼 별도의 탭에서 뷰어로 열립니다. 확대/축소(**확대**, **축소**, **너비에 맞춤**, **전체 페이지**, Ctrl과 마우스 휠로도 가능), 세 가지 보기(**한 쪽 보기**, **두 쪽 보기**, **연속 스크롤**), **미리보기**, 책의 **목차**, **전체 화면**을 제공합니다. 만화처럼 오른쪽에서 왼쪽으로 읽는다고 밝힌 책은 그대로 표시됩니다. 왼쪽 화살표가 앞으로 넘기고, 두 쪽 보기에서는 표지를 따로 두어 인쇄본과 같은 쪽 짝을 맞출 수 있습니다. 화살표, Home, End로 페이지를 넘기고 F로 전체 화면을 켭니다. 파일은 브라우저 저장소에 그대로 보관되어 조금씩 읽히므로 한꺼번에 불러오지 않으며, 뷰어는 책마다 페이지, 보기, 확대 비율을 기억합니다.

**이미지 폴더.** 이미지로 된 만화는 **이미지 폴더 선택**을 누르거나 폴더를 끌어다 놓아 가져옵니다. 이미지가 있는 폴더는 각각 책 한 권이 됩니다. 권처럼 보이는 하위 폴더만 있으면, 즉 이름(“第01巻”, “Vol. 2”, “v03”)이나 이미지가 200장쯤 들어 있는 것으로 보아 권이면, 권마다 따로 들어가고 이름이 번호뿐이면 시리즈 이름이 앞에 붙습니다. 장처럼 보이면 책 한 권의 목차가 됩니다. 페이지는 자연스러운 순서로 정렬되며, 이름이 “cover.jpg”여도 표지가 맨 앞에 옵니다. 이미지가 아닌 파일은 무시하고, ComicInfo.xml이 있으면 제목과 읽는 방향을 가져옵니다. 책은 각각 CBZ로 저장되며, 이미지를 다시 압축하거나 메모리에 복사하지 않습니다. **두 쪽 보기**에서 가로로 긴 페이지, 즉 한 장으로 스캔된 두 쪽은 따로 표시됩니다.

**컬렉션과 진도.** 책은 시리즈와 그 권들, 또는 한 주제의 책처럼 컬렉션으로 묶을 수 있습니다. 여러 권이 든 폴더는 그 이름의 컬렉션으로 바로 들어오고, 같은 폴더에서 가져온 새 권도 그 컬렉션에 추가됩니다. **새 컬렉션**으로 이름, 종류(**만화**, **소설**, **공부**, **기타**), 설명을 정해 직접 만들 수 있습니다. 컬렉션 안에서 **책 추가**는 책장의 책을 가져오고, **여기로 가져오기**는 파일을 그 컬렉션으로 바로 가져오며, **표지**는 안에 있는 책의 표지나 직접 고른 이미지를 고르고, **컬렉션 없애기**는 안의 책을 책장에 남깁니다. 각 책은 얼마나 읽었는지 보여 주고, 마지막 페이지에 이르면 **완독**이 됩니다. 책 메뉴에서는 다른 컬렉션으로 옮기기, 표지 바꾸기, 다 읽음으로 표시, 처음부터 다시 읽기를 할 수 있습니다. 책장 위의 **계속 읽기**는 읽고 있는 책으로 바로 이어지고, **읽는 중**, **읽지 않음**, **완독** 필터는 컬렉션 안의 책까지 포함해 각각을 보여 줍니다. PDF는 가져올 때부터 표지와 쪽수가 있으며, 뷰어의 **이 페이지를 표지로 사용**으로 어느 페이지든 표지로 정할 수 있습니다.

**페이지 글.** **페이지의 글 읽기** 버튼은 이미지 페이지의 글을 내 컴퓨터에서 GPU로 인식해 페이지 위에 놓습니다. 마우스를 올리면 줄마다 표시되고, 누르면 옆에 후리가나와 찾아볼 수 있는 단어, 단어 패널과 카드 만들기와 함께 열립니다. 모드는 두 가지입니다. **책**은 인쇄된 책과 스캔한 PDF용이고, **만화**는 말풍선과 세로쓰기용으로 후리가나를 본문과 헷갈리지 않습니다. **책** 모드에서는 인쇄된 후리가나가 본문에 섞이지 않고 두 단으로 된 페이지는 단마다 읽으며, **만화** 모드에서는 말풍선이 칸 순서를 따르고 워터마크와 쪽 번호는 빠집니다. 오른쪽에서 왼쪽으로 읽는 책은 **만화** 모드로 시작합니다. 이미 자체 글이 들어 있는 PDF에서는 그 글을 씁니다. 그것이 다른 문자 인식 프로그램이 넣은 오류가 많은 글이라면, **PDF 글**을 끄면 Kotonoha가 그 페이지도 읽습니다. 스캔한 PDF에서는 화면에 그린 페이지가 아니라 스캔 이미지를 원래 해상도 그대로 읽으므로 오류가 훨씬 적습니다. 처음에는 모델을 내려받고(책 25 MB, 만화 178 MB), 각 페이지는 한 번만 1~2초 안에 읽습니다. 문자 인식은 비슷한 글자를 헷갈리거나 수식의 아래 첨자를 놓칠 수 있으며, 원본 이미지는 그대로 보입니다. 다음 페이지들은 도착하기 전에 미리 읽어 두므로, 페이지를 넘기면 글이 이미 준비되어 있습니다. 어떤 줄에 글자가 잘못 나오면 줄 패널의 **편집**으로 글을 직접 쓸 수 있습니다. 편집한 내용은 따로 저장되어 페이지를 다시 읽어도 사라지지 않으며, **복원**을 누르면 읽은 글로 돌아갑니다. 서재의 각 책 카드에서 **처리**를 누르면 모든 페이지를 한 번에 문자 인식으로 읽고 진행 상황을 보여 줍니다. 일시 정지했다가 나중에 이어서 해도 잃는 것이 없으며, 끝나면 책에 **글 준비 완료**가 표시되고 문자 인식이 켜집니다.

**메모와 책갈피.** 페이지 책에서 **이 페이지에 책갈피**는 페이지에 책갈피 끈을 달며, 미리보기에서도 보입니다. 줄 패널에서 **강조**는 그 줄을 네 가지 색 가운데 하나로 칠하고, **밑줄**은 밑줄을 긋습니다. 단어를 고르거나 끌어서 구간을 선택하면 그 부분만 표시할 수 있습니다. 강조마다 **코멘트 달기**로 코멘트를 붙일 수 있습니다. **메모 추가**는 누른 페이지 위치에 메모를 붙이며, 열어서 읽거나 고칠 수 있습니다. **메모와 책갈피** 패널은 모든 것을 페이지별로 모아 각 항목으로 이동하거나 편집·삭제할 수 있게 하고, **복사**는 이를 글로 클립보드에 넣습니다. 강조는 페이지 이미지 위에 저장되므로 문자 인식이 페이지를 다시 읽어도 제자리에 남으며, 모두 백업에 포함됩니다.

**책에서 찾기.** **책에서 찾기**(또는 Ctrl+F)는 글이 있는 모든 페이지에서 단어를 찾습니다. PDF에 들어 있는 글과 문자 인식이 읽어 낸 글을 대상으로 하며, 편집한 내용이 우선합니다. 대소문자, 전각·반각, 히라가나와 가타카나를 구분하지 않으며, 일본어에서는 두 줄에 걸쳐 나뉜 단어도 찾습니다. 결과는 페이지별로 앞뒤의 짧은 글과 함께 나오고, Enter는 다음 결과로, Shift+Enter는 이전 결과로 이동하며, 찾은 부분은 페이지에 표시됩니다. 문자 인식이 아직 읽지 않은 페이지는 찾지 않습니다. 패널에 그 수가 나오며, **처리**를 누르면 한 번에 모두 읽습니다.

**글 보기.** **글로 보기**는 페이지 이미지 대신 그 글을 보여 줍니다. 줄은 문단으로 합쳐지고 제목은 따로 나오며, 노트의 읽기 도우미가 함께합니다: 후리가나, 색, 이해도, **소리 내어 읽기**, 카드를 만드는 단어 패널. 만화에서는 말풍선 하나가 한 문단입니다. 페이지는 이미지와 똑같이 넘기며, **페이지 보기**로 이미지로 돌아갑니다. 책마다 마지막으로 쓴 보기를 기억합니다.

**Claude로 검토.** **Claude로 글 검토**는 페이지 이미지와 읽어 낸 글을 Claude에 보내며, Claude는 이미지와 맞지 않는 줄만 제안합니다. 변경은 글자 단위로 보여 주고, 적용할 것을 고를 수 있으며, **적용**을 누르기 전에는 아무것도 바뀌지 않습니다. 검토한 줄은 패널에 ‘Claude로 검토함’이 표시되고, **복원**으로 원래대로 되돌릴 수 있습니다. Claude 키가 필요합니다. 이 작업은 Claude Haiku 5.5를 쓰며 페이지당 1센트(미국 달러)도 들지 않고, **설정**의 ‘페이지 글 검토’에서 모델을 바꿀 수 있습니다. 같은 글로 같은 페이지를 다시 검토해도 다시 비용이 들지 않습니다. 검토하는 페이지는 다른 요청처럼 Claude로 보내지며, 책의 나머지는 컴퓨터를 떠나지 않습니다.

**텍스트 책.** 소설 같은 텍스트 EPUB은 뷰어에서 원래 서식 그대로 열립니다. 장, CSS, 루비, 삽화, 세로쓰기를 살리고, 그 위에 웹에서처럼 페이지 리더가 색과 후리가나를 더하며, 단어를 클릭하면 단어 패널이 열립니다. 화살표, Page Up, Page Down, 마우스 휠로 페이지를 넘기며, 세로쓰기 책은 왼쪽으로 나아가고 장이 끝나면 다음 장으로 넘어갑니다. **목차**로 각 장에 가고, 책 안의 링크도 작동하며, **확대**와 **축소**로 글자 크기를 바꾸고, **세로쓰기**를 끄면 세로쓰기 책을 가로로 읽을 수 있습니다. 뷰어는 장과 정확한 위치를 기억합니다. 책에 든 어떤 것도 실행되거나 인터넷에서 무언가를 불러오지 않습니다.

**텍스트가 든 PDF.** PDF에 텍스트가 들어 있으면 OCR도 다운로드도 없이 바로 씁니다. 줄을 누르기만 하면 됩니다. 텍스트가 든 PDF나 **책** 모드로 읽은 페이지에서 단어를 누르면 단어 패널이 바로 열리고 그 단어가 페이지 위에 표시됩니다.

**로컬 플레이어.** ffmpeg.wasm으로 MKV 내장 자막과 오디오 트랙 선택을 지원하며 내 파일을 재생합니다.

**단어와 평가.** 탐색기는 어휘를 상태별로 나열하고, 수준 평가는 처음에 아는 단어 수를 추정합니다.

**JLPT.** 사이드바의 **JLPT**는 N5부터 N1까지 각 급수의 어휘, 한자, 문법과 그중 이미 아는 것을 모아 보여 줍니다. 급수 카드마다 아는 단어와 한자 수를 세고, 고리 그래프로 어휘를 얼마나 아는지 보여 줍니다. **어휘**에서는 단어마다 상태가 표시되며, 그 줄에서 하나씩 바꾸거나 한꺼번에 바꿀 수 있습니다. **목록의 …개 모두 선택**과 상태를 고르면 예를 들어 이미 아는 N5 단어를 한 번에 표시합니다. **한자**에서는 아는 단어에 들어 있으면 그 한자를 아는 것으로 칩니다. 누르면 읽는 법, 뜻, 획순, 그 한자가 들어간 해당 급수의 단어가 나옵니다. **문법**에서는 항목마다 뜻이 표시되고, 펼치면 지금까지 본 동영상, 웹 페이지, 책에서 그 항목이 나온 문장이 문형을 강조해 나타납니다. **Claude로 설명**은 예문과 함께 설명합니다. JLPT에는 공식 목록이 없습니다. 어휘와 한자는 널리 쓰이는 Jonathan Waller의 목록(CC BY)이고, 문법은 약 500개 항목의 자체 목록입니다.

**사전.** 사전 페이지는 창의 너비를 모두 씁니다. 왼쪽에는 결과 목록, 가운데에는 고른 단어, 오른쪽에는 그 단어와 관련된 내용이 있습니다. 너비가 좁아지면 목록은 옆으로 넘기는 한 줄이 되고 오른쪽 열은 아래로 내려가며, 아주 좁은 창에서는 모두 한 열에 표시됩니다. 가나로 검색하면 그렇게 읽는 단어를 따로따로 보여 주고(のむ → 飲む, 呑む), 한자로 검색하면 그 말로 시작하는 단어도 함께 보여 줍니다(日本 → 日本語, 日本人). 각 뜻은 풀이를 한데 모아 보여 주고, 그 위에 품사와 용법(5단 동사, 타동사, 구어)을 사전별로 나누어 표시합니다. 페이지는 탭이 하나도 열리지 않은 채로 열리며, 음성, 이미지, Claude는 각 버튼을 눌러야 나옵니다. 오른쪽에는 그 단어의 한자(JLPT 급수, 읽는 법, 뜻), 영어판 JMdict에서 가져온 **반대말**(예: 上手의 下手)과 **함께 보기**, 뜻이 같은 자주 쓰는 말인 **같은 뜻**(예: 食べる의 食う와 召し上がる), **읽는 법이 같은 말**(예: 橋의 箸와 端), Claude에게 묻는 **비슷한 단어와 그 차이**가 있습니다. 모든 목록은 카드로, 읽는 법은 단어 위에, 뜻은 아래에 있고, 자주 쓰는 말에는 별이, 이미 알거나 배우고 있는 말에는 점이 붙습니다.

**본 곳.** 단어 아래에는 그 단어가 나온 동영상과 글의 문장이 나오며, 읽는 법은 위에 달리고 활용형이라도 단어가 강조됩니다. 문장 속 다른 단어를 누르면 그 단어를 찾습니다. 동영상에서 나온 문장에는 들린 시간과 **12:34(으)로 돌아가기**가 있어, 동영상 탭이 열려 있으면 그 탭으로, 아니면 새로 열어서 그 순간으로 이동합니다. 동영상 위 단어 패널의 **예문** 탭에도 같은 버튼이 있습니다.

**한자 한 글자.** 한자 한 글자(예: 愛)를 검색하면 그 한자의 페이지가 열립니다. 크게 한 획씩 보여 주는 쓰는 법, 뜻, JLPT 급수, 획수, 읽는 법(음독과 훈독), KanjiVG에서 가져온 **구성 요소**(부수와 소리 부분을 표시하며, 요소마다 자기 페이지가 있음), 이미 알거나 배우고 있는 **愛이(가) 들어간 내 단어**, 그 한자가 들어간 자주 쓰는 말인 **愛이(가) 들어간 단어**(많이 쓰는 것부터), 한자 읽기대로 읽지 않는 자주 쓰는 말인 **愛이(가) 들어간 특수한 읽기**(可愛い 등. 今의 경우 今日와 今朝), 반대말(있다면), 본 곳, 인쇄체·책 글꼴·손글씨로 본 **글자 모양**, Claude에게 묻는 **기원과 기억하는 법**이 있습니다. 그 한자가 단어이기도 하면 위쪽의 **단어**를 눌러 단어로 볼 수 있습니다.

**한자 사전.** **한자 (Kanjium, KANJIDIC)** 사전을 설치하면 한자 페이지에 훨씬 많은 정보가 나옵니다. 페이지에서 바로 **설치**를 누르거나 **설정, 사전**에서 설치할 수 있습니다. 약 3MB이며 한자 6812자가 들어 있습니다. 뜻은 영어로 표시되며, 인터페이스가 스페인어일 때는 약 2500자의 뜻이 스페인어로 나옵니다. 한자 옆에는 속한 공식 표(일본에서 배우는 학년이 함께 나오는 **상용한자**, 이름에 쓸 수 있는 **인명용 한자**, 또는 표외 한자), 한자 시험인 **한자검정**의 급수, 사용 빈도 순위가 표시됩니다. 읽기는 나누어 보여 줍니다. 먼저 공식 표에 있는 읽기가 나오고, **기타** 아래에 표에 없는 읽기가 나옵니다. **이름에서**는 인명에만 쓰이는 읽기를 모읍니다. 음독마다 어느 시대에 들어왔는지(**오음**, **한음**, **당음**) 표시하며, 공식 읽기이지만 거의 쓰이지 않는 것은 점선 테두리로 표시합니다. 그 아래에는 수업에서 부르는 이름(さんずい)과 번호가 붙은 **부수**, 그리고 **만들어진 원리**(상형자, 지사자, 회의자, 형성자)가 있습니다. 더 아래의 **이 글자에서 소리를 받는 한자**와 **같은 소리 부분을 가진 한자**는 소리를 주는 부분이 같은 한자를 모읍니다(예: 青이 들어간 晴, 清, 精). **이 글자가 들어간 한자**는 그 밖의 한자, **모양이 비슷한 한자**는 읽을 때 헷갈리기 쉬운 한자입니다. **반대 뜻의 한자**와 **뜻이 비슷한 한자**, 악센트로 구별되는지도 알려 주는 **읽기가 같은 한자**(예: かみ로 읽는 神, 紙, 髪), **옛 글자체와 이체자**(예: 国의 옛 글자체 國)도 있습니다. 옛 글자체의 페이지는 지금은 어떻게 쓰는지 알려 줍니다. 데이터는 Uros O.의 [Kanjium](https://github.com/mifunetoshiro/kanjium)과 EDRDG의 KANJIDIC에서 가져옵니다.

**쓰기 연습.** 한자 페이지에서 **연습**을 누르면 획순 대신 마우스, 펜, 손가락으로 쓸 수 있는 칸이 나옵니다. **따라 쓰기**에서는 한자가 배경에 보이고, 점이 지금 쓸 획의 시작 위치를 알려 줍니다. **외워서 쓰기**에서는 칸이 비어 있습니다. 획은 손을 뗄 때마다 확인합니다. 맞으면 제자리에 남고, 틀리면 지워지며 이유를 알려 줍니다(방향이 반대임, 아직 차례가 아닌 다른 획임, 모양이 다름). 같은 획을 두 번 틀리거나 **힌트**를 누르면 그 획을 직접 그려서 보여 줍니다. 마지막 획을 취소하거나 전부 지울 수 있고, 다 쓰면 복습할 획을 알려 줍니다.

**뜻과 분류로 찾기.** 영어나 스페인어로 “dog”처럼 쓰면 그 뜻을 가진 자주 쓰는 일본어 단어를 보여 줍니다. 검색어는 JLPT 문법과도 비교되어, 형태(わけ)나 뜻(“although”)으로 찾을 수 있고, 항목을 펼치면 예문과 설명이 나옵니다. 첫 화면의 **사전 둘러보기**는 JMdict의 표시에 따라 의성어·의태어, 특수한 읽기의 단어, 사자성어, 속담, 관용구, 문어와 고어, 구어와 속어, 경어를 카드로, 자주 쓰는 것부터 모아 보여 줍니다. 뜻으로 검색하기, 분류, 한자가 들어간 단어에 쓰이는 색인은 몇 초에 걸쳐 한 번만 만들어 저장합니다. 사전이 바뀔 때만 다시 만듭니다.

**크기와 글꼴.** 검색창 옆의 **−**와 **+**로 단어 크기를 바꾸고, 그 옆 버튼으로 전체 너비와 가운데 한 열을 오갑니다. **설정, 사전, 사전 페이지**에서는 일본어 글자의 **글꼴**도 고를 수 있습니다. 복잡한 한자도 읽기 쉬운 기본값 **고딕**, Kotonoha의 **둥근 글꼴**, **책 글꼴**, 획을 따르는 일본 교과서 글꼴인 **손글씨**가 있습니다. 시스템 글꼴이라 없는 글꼴은 가장 비슷한 글꼴로 대신합니다.

**이미 아는 문법.** 문법 항목마다 **새 항목**, **학습 중**, **익힘**으로 표시할 수 있습니다. 자막 아래의 항목을 눌러 여는 말풍선, 단어 패널, **JLPT** 화면, 사전에서 모두 됩니다. 익힌 항목은 자막 아래에 더 이상 표시되지 않고, 학습 중인 항목에는 노란 줄이 생깁니다. 동영상의 한 줄에 어떤 항목이 나올 때마다 Kotonoha가 기록하며, **본 곳**에서 그 항목이 나온 동영상과 마지막 문장을 보여 줍니다. **객관식 카드**는 카드 만들기에 빈칸이 있는 문장과 선택지 네 개(그중 세 개는 Claude가 고른 헷갈리기 쉬운 항목)를 앞면에, 정답과 나머지가 맞지 않는 이유를 뒷면에 담은 카드를 준비합니다. **설정 → Anki**의 **Anki에서 문법 가져오기**는 덱의 지정한 필드에서 Kotonoha가 아는 항목, 곧 JLPT 목록의 501개를 찾습니다. 간격이 21일 이상인 카드의 항목은 익힘으로 표시됩니다.

**몰입 시간.** Kotonoha는 공부하는 언어로 듣고 읽은 시간을 셉니다. 그 언어의 자막이 있는 재생 중인 동영상(내 파일 포함), 뷰어에서 연 책, 그리고 읽는 동안의 노트나 라이브러리 텍스트입니다. 읽는 동안이란 페이지가 화면에 보이고 최근 3분 안에 그 페이지에서 무언가를 한 경우를 말합니다. 일시정지한 동영상은 세지 않습니다. **홈**에는 오늘, 최근 7일, 합계 시간과 하루 5분 이상인 날이 이어진 **연속** 일수, 요일별 막대, 가장 많이 보고 읽은 것이 나옵니다. 언어마다 따로 세며, 백업에도 들어갑니다.

## 영어 공부하기

언어는 환영 화면, **설정, 언어와 수준**, 또는 확장 프로그램 메뉴에서 고릅니다. 언어마다 단어, 사전, 카드, 서재, 읽기 설정이 따로 있으며, 다른 언어로 돌아가도 모든 것이 그대로 있습니다. 인터페이스, Claude 키, 비용은 공통입니다.

이 안내에서 설명하는 내용은 모두 똑같이 작동하며, 차이는 다음과 같습니다.

| 항목 | 영어 |
|---|---|
| 사전 | 인터페이스 언어의 Wiktionary로, 정의와 짧은 번역의 두 부분입니다. 인터페이스가 영어이면 영영 사전을 제안하며, 다운로드 약 110MB, 저장 공간 약 220MB입니다 |
| 발음 | 단어 패널에 미국식과 영국식 IPA가 표시됩니다. 단어 위 표시는 처음에 꺼져 있으며 **표시** 패널에서 켭니다. 어느 쪽을 쓸지는 **설정, 언어와 수준**에서 고릅니다 |
| 실제 발음 | 단어 패널의 **실제 발음** 탭은 이어서 말할 때의 문장을 보여 주며, 바뀌는 부분 위에 실제 소리를 적습니다. 축약(*going to* → *gonna*), 약형(*to* → *tə*), 연음(*turn off* → *tur‿noff*), t나 d와 *you*의 결합(*meet you* → *meechu*), 미국식 부드러운 t(*get it* → *ge‿dit*)를 설명과 함께 보여 줍니다. Claude 없이 규칙으로 계산합니다 |
| 악센트 색 | 강세 음절을 나타냅니다. 첫 음절, 가운데 음절, 마지막 음절입니다. 이것도 처음에는 꺼져 있습니다 |
| 형태 | 패널이 각 형태가 어떤 단어에서 왔는지 알려 줍니다. *went*는 *go*를, *didn't*는 *do*를 엽니다 |
| 구동사 | 떨어져 있어도 패널이 찾습니다. *picked it up*에서는 *pick up*이 나타납니다. 관용 표현도 마찬가지입니다 |
| 문법 | A1부터 C2까지의 문법 항목을 같은 방식으로 Claude가 확인합니다 |
| 페이지 리더 | 영어는 거의 모든 페이지에 있으므로 처음에는 꺼져 있습니다. 확장 프로그램 메뉴나 **설정, 페이지 리더**에서 켭니다 |
| 획순과 읽는 법 수정 | 제공하지 않습니다 |
| 코믹스 | 뷰어의 **코믹스** 모드(일본어에서는 **Manga**)는 말풍선마다 책 인식기로, 칸 순서대로 왼쪽에서 오른쪽으로 읽습니다. 측정: 테스트 페이지 문자 오류율 0.4 %, 손글씨로 쓴 1922년 *Krazy Kat* 페이지 12 % |
| 책 OCR | 19세기 실제 스캔본으로 측정: 문자 오류율 1.5 %, 거의 모두 머리글 |
| 문장 음성 | **설정, 음성**의 **브라우저 안의 신경망 음성**은 키 없이 이 컴퓨터에서 Kokoro로 문장을 읽으며, 미국과 영국 목소리 여섯 가지가 있습니다. 처음에 92 MB를 내려받고, 새 문장은 프로세서에서 몇 초 걸린 뒤 저장됩니다 |

## 독일어 공부하기

영어와 같은 방법으로 고르며, 모든 기능이 같게 작동합니다. 차이점은 다음과 같습니다.

| 항목 | 독일어 |
|---|---|
| 사전 | 인터페이스 언어의 Wiktionary로, 정의와 짧은 번역이 있으며, 여기에 독일어–영어 사전이 더해집니다. 이 사전은 각 단어의 활용형과 격변화형을 담고 있어 항상 추천됩니다. 다운로드 약 17MB입니다. 인터페이스가 독일어이면 독일어–독일어 사전(약 55MB)도 추천합니다 |
| 형태 | 단어 패널은 각 형태가 나온 단어를 열고 어떤 형태인지 알려 줍니다. *ging*은 *gehen*(과거형), *Häuser*는 *Haus*(복수형)를 엽니다. *schönen*처럼 두 단어에서 나올 수 있으면 더 자주 쓰이는 쪽을 고릅니다. 관사는 *der*와 *ein*으로, *sein*의 형태는 *sein*으로 정리합니다 |
| 분리 동사 | 접두사가 문장 끝에 있어도 패널이 찾아냅니다. *fängt morgen an*에서는 *anfangen*이 나타납니다. 관용 표현도 마찬가지입니다 |
| 발음 | 단어 패널에 지역 변이를 뺀 IPA를 보여 줍니다. 단어 위의 발음은 처음에 꺼져 있으며, 강세 음절을 나타내는 악센트 색상도 마찬가지입니다 |
| 문법 | Perfekt, Konjunktiv, 수동태, 동사가 끝에 오는 종속절 등 A1부터 C2까지의 문법 항목을 같은 방식으로 Claude가 확인합니다 |
| 전사 | 말소리에는 Parakeet, 노래에는 Whisper Turbo를 씁니다. 실제 녹음에서 Parakeet는 대소문자와 문장 부호를 넣었고, 걸린 시간은 Whisper의 절반도 안 되었습니다 |
| 페이지 리더 | 처음에는 꺼져 있습니다. 확장 프로그램 메뉴나 **설정, 페이지 리더**에서 켭니다 |
| 획순과 읽기 수정 | 제공하지 않습니다 |
| 코믹스 | 영어와 같은 **코믹스** 모드, ä, ö, ü, ß 포함: 테스트 페이지 오류율 0.4 % |
| 책 OCR | 현대 글꼴은 잘 읽습니다: 글꼴 네 가지 테스트 페이지 오류율 0.03 %. 옛 책의 프락투어(Fraktur)는 읽지 못합니다: 1919년 페이지에서 네 글자 중 세 글자를 틀렸습니다 |
| 문장 음성 | **브라우저 안의 신경망 음성**은 키 없이 이 컴퓨터에서 Thorsten 목소리의 Piper로 문장을 읽습니다. 처음에 63 MB를 내려받고, 한 문장을 1초 안에 읽습니다 |

## Claude 비용

홈 화면의 **Claude 비용** 카드에는 설정에 입력한 크레딧 대비 이번 달 비용, 일별·모델별 차트, 작업별 내역, 요청별 토큰 기록이 표시됩니다. 비용은 API가 보고한 토큰과 공개 가격으로 계산하며, 이 브라우저의 이 확장 프로그램에서 보낸 요청만 집계합니다.

영상당 가장 많이 드는 것은 자동 자막 수정이고, 그다음이 번역과 읽는 법·뜻·문법 검토입니다. 검토는 재생 위치 앞쪽 몇 분을 다루며 재생에 따라 진행되고, 검토한 내용은 저장됩니다. **자막 생성**에서 끄거나 **영상 전체 검토**로 영상 전체를 요청할 수 있습니다. [비용 연구](costs.md)에 영상별·월별 측정값이 있습니다.

단어 요청의 사용량을 정하는 설정은 세 가지입니다.

| 설정 | 위치 | 기본값 | 효과 |
|---|---|---|---|
| 단어를 열 때 뜻 묻기 | 설정, Claude | 꺼짐 | 새 단어를 열 때마다 요청이 됩니다 |
| 전체 대본을 맥락으로 | 설정, Claude | 꺼짐 | 이름과 지칭에 맥락을 더 주지만 요청당 비용이 늘어납니다 |
| 첫 탭 | 설정, 사전 | 사전만 | Claude 탭을 고르면 단어를 열 때마다 요청합니다 |

## 데이터와 백업

모든 데이터는 브라우저의 IndexedDB에 저장됩니다. **설정, 내 데이터**에서 사용한 모든 언어의 단어, 카드, 컬렉션과 노트를 포함한 서재, 생성된 자막, 수정 내용, 몰입 시간, 문법 표시와 설정, 비용 기록이 담긴 파일 하나를 내보내고 가져올 수 있습니다. API 키와 사전은 포함되지 않습니다. 버전 0.4.0 이전의 백업은 일본어로 복원됩니다.

**전체 사본.** **폴더로 내보내기**는 책 파일, OCR이 읽은 내용과 편집한 내용, 받아쓰기까지 날짜가 붙은 폴더에 저장합니다. **폴더에서 복원**은 이미 있는 것을 지우지 않고 다른 사본에 모두 넣습니다. 사본마다 데이터를 따로 보관하므로, Kotonoha를 다른 컴퓨터나 고정 식별자로 설치한 사본으로 옮길 때 씁니다. 사전과 모델은 설정에서 다시 설치합니다.

**새 버전.** Kotonoha는 하루에 한 번 GitHub에 최신 공개 버전을 물어봅니다. 설치된 버전보다 새로우면 **홈**과 확장 프로그램 메뉴에 그 페이지 링크와 함께 알려 줍니다. 한 버전의 알림을 닫으면 다음 버전이 나올 때까지 다시 나오지 않습니다. **설정, 버전**에서 설치된 버전을 보고, 직접 확인하고, **새 버전 알림**으로 알림을 끌 수 있습니다. 도우미가 설치되어 있고 폴더에서 불러온 사본이라면, 알림과 **설정, 버전**에 **지금 업데이트**가 나옵니다. 도우미가 패키지를 내려받아 그 버전의 `SHA256SUMS.txt`로 SHA-256을 확인하고, 식별자를 그대로 둔 채 확장 프로그램 폴더에 복사하며, 진행 중인 작업이 없으면 확장 프로그램이 스스로 다시 로드됩니다. 스토어에서 설치한 사본은 알아서 업데이트됩니다.

## 키보드 단축키

전체 목록은 영상 위 단축키 패널에 있습니다. **설정, 키보드 단축키**에서 바꿀 수 있고, 키 위치를 기준으로 하므로 한국어·러시아어 키보드나 일본어 입력을 켠 상태에서도 작동합니다.

| 분류 | 단축키 | 동작 |
|---|---|---|
| 바 | `Alt+X` | 바 고정 또는 해제 |
| | `Alt+V` | 누르는 동안 표시 |
| | `Alt+T` | 번역기 열기 |
| 단어 | `1` 또는 `U` | 모르는 단어로 표시 |
| | `2` 또는 `T` | 추적 |
| | `3` 또는 `K` | 아는 단어로 표시 |
| | `4` 또는 `I` | 무시 |
| | `N` | 다음 모르는 단어로 이동 |
| | `Alt+S` | 사전에서 찾기 |
| 카드 | `Q`, `Alt+Q` | 카드 만들기 |
| | `E` | 카드 제작기로 보내기 |
| | `Alt+Shift+M` | 오디오 캡처 허용 |

## 자주 발생하는 문제

| 증상 | 원인과 해결 방법 |
|---|---|
| 컴파일 후 아무것도 바뀌지 않습니다 | 브라우저가 이전 서비스 워커를 유지합니다. 확장 프로그램 페이지에서 **새로고침**을 눌러야 합니다 |
| ‘영상을 들으려면 오디오 캡처를 켜야 합니다’ | Chrome은 탭 캡처에 사용자 동작을 요구합니다. 영상 탭에서 `Alt+Shift+M` 또는 확장 프로그램 메뉴의 스위치로 해결합니다 |
| `Alt+Shift+M`, `Alt+Shift+K`, `Alt+Q` 같은 단축키가 반응하지 않습니다 | Chrome은 다른 확장 프로그램이 이미 가진 키를 비활성화 상태여도 할당하지 않으며 알려 주지도 않습니다. 확장 프로그램 메뉴와 단축키 패널에 실제 키가 표시되고, `chrome://extensions/shortcuts`에서 바꿀 수 있습니다 |
| `Alt+R` 또는 `Alt+Z`가 Radeon Software를 엽니다 | AMD 그래픽 컴퓨터에서 그 앱이 쓰는 단축키입니다. Kotonoha는 `Alt+Shift+M`과 `Alt+V`를 씁니다 |
| 인터페이스에 흐림 효과가 없습니다 | 하드웨어 가속을 끄면 영상 위 흐림 효과가 프레임을 잃으므로, 확장 프로그램이 더 불투명한 배경으로 대체합니다 |
| Whisper가 매우 느립니다 | 브라우저가 GPU에 접근하지 못합니다. 브라우저 설정의 하드웨어 가속을 확인해야 합니다 |
| 도우미가 설치된 것으로 나타나지 않습니다 | 설치 프로그램을 실행한 뒤 확장 프로그램을 다시 로드해야 합니다. 다른 폴더에서 로드했다면 `-Extension`으로 식별자를 지정해야 합니다 |
| 영상을 내려받을 수 없습니다 | 연령 제한, 비공개, 유료 영상은 yt-dlp가 가져올 수 없습니다. 재생하면서 전사할 수 있습니다 |
| YouTube 자막이 비어 있습니다 | 요청은 플레이어가 서명합니다. 영상을 몇 초 재생하면 됩니다 |
| Anki가 연결되지 않습니다 | AnkiConnect가 있는 Anki가 열려 있어야 하고, 그 구성에서 확장 프로그램의 출처를 허용해야 합니다. 확장 프로그램이 처음에 권한을 요청합니다 |
