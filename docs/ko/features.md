# 기능

버전 0.15.0의 각 기능 상태와 검증 방법입니다.

| 검증 | 의미 |
|---|---|
| 자동 | 확장 프로그램을 로드한 Edge에서 처음부터 끝까지 테스트 |
| 시뮬레이터 | 실제 코드가 Claude API 또는 AnkiConnect 모의 서버를 상대로 전부 실행 |
| 모방 페이지 | 여기에 더해 Netflix나 YouTube와 같은 플레이어 구조의 페이지에서 실행 |
| 실제 세션 | YouTube에서 Chrome, 실제 세션, Claude API로 직접 확인 |
| 대기 | 사이트의 실제 세션이나 자신의 자격 증명이 필요 |

## 설계 원칙

| 원칙 | 적용 |
|---|---|
| 뜻은 문장에 달려 있습니다 | ‘이 문장에서’ 블록이 맥락상의 뜻을 알려 주고, 비유적이거나 시적인 용법을 표시하며, 카드 맨 앞에 옵니다 |
| 올바른 읽는 법 | Claude가 각 줄의 읽는 법을 검토하고 직접 고칠 수도 있습니다 |
| 넓은 맥락 | Claude는 문장 주변 40줄과 번역을 받습니다. 전체 대본은 수정할 때 보내고 요청할 때는 선택 사항입니다 |
| 두 번 내지 않습니다 | 답변은 단어와 문장별로, 검토 내용은 줄 텍스트별로 저장합니다. 중단된 답변은 끝까지 받아 저장하고, 동시에 온 같은 요청은 하나를 공유합니다 |
| 필요할 때만 Claude | 패널은 사전으로 열리고, 검토는 영상 전체가 아니라 앞으로 볼 구간을 다룹니다 |
| 보고 있는 것부터 | 번역, 수정, 검토는 재생 위치를 기준으로 구간을 정렬합니다 |
| 컴퓨터는 계속 쓸 수 있습니다 | 전사는 쉬면서 사용 상황에 맞추고, 실패가 반복되면 멈춥니다 |
| 페이지를 다시 쓰지 않습니다 | 웹 밑줄은 내용에 아무것도 추가하지 않고 CSS Custom Highlight API를 씁니다. 후리가나가 들어가지 않는 곳의 줄 간격만 넓힙니다 |
| 로컬 데이터 | 모든 것이 브라우저에 남고, 전사 오디오는 컴퓨터 밖으로 나가지 않습니다 |

## 알려진 제한

| 제한 | 내용 |
|---|---|
| 학습 언어 | 일본어, 영어, 독일어. 새 언어마다 `src/lenguas`에 자체 패키지가 필요합니다 |
| 영어 분석 | 확장 프로그램에 들어가는 작은 모델이 처리합니다. 모호한 문장에서는 품사를 잘못 판단할 수 있고, 그러면 단어 아래 번역도 틀릴 수 있습니다. 단어 패널에는 여전히 모든 정의가 표시됩니다 |
| 독일어 분석 | 사전의 형태에서 나옵니다. 독일어–영어 사전이 없으면 각 단어가 그대로 원형이 됩니다. 두 후보 단어 사이에서는 문장을 보지 않고 빈도로 정하며, Claude가 줄을 검토할 때 틀린 것을 고칩니다 |
| 독일어 복합어 | 사전에 없는 복합 명사는 부분으로 나누지 않습니다 |
| 영영 사전 | 크기가 큽니다. 다운로드 약 110MB, 저장 공간 약 220MB입니다. 설치와 삭제에 몇 분이 걸립니다. 인터페이스가 영어일 때만 제안합니다 |
| 인터페이스 번역 | AI의 도움으로 작성했으며 아직 원어민 검토를 받지 않았습니다. 오류는 `idiomas/`에서 수정합니다 |
| 페이지 리더 | 메인 프레임에서만 작동해 iframe 안의 텍스트에는 닿지 않습니다. 페이지가 캔버스나 이미지에 그린 것은 텍스트가 아닙니다 |
| Claude 프롬프트 | 다른 언어로 답을 요청할 때도 지시문은 스페인어로 남아 있습니다 |
| 플랫폼 | 데스크톱 Chrome과 Edge. 로컬 도우미는 Windows용입니다 |
| DRM이 있는 이미지 | Netflix 등 보호된 사이트에서는 브라우저가 화면을 검게 전달합니다. 사이트가 제공하면 카드에 에피소드의 공식 이미지가 들어갑니다 |
| DRM이 있는 오디오 | 보호된 사이트는 캡처에 소리를 전달하지 않을 수 있습니다. 한 영상에서 무음 문장이 두 번 연속되면 녹음을 위해 다시 재생하지 않습니다 |
| 뷰어 | 문자 인식은 비슷한 글자(エ와 工, ー와 一)를 헷갈리거나 가끔 글자를 빠뜨리고 수식의 아래 첨자를 놓칠 수 있습니다. 원본 이미지는 항상 보입니다. 책 모드는 가로쓰기로 측정했습니다. DRM이 있는 책은 열리지 않습니다. 책 파일은 백업에 포함되지 않아 다른 컴퓨터에서는 다시 가져와야 합니다 텍스트 EPUB은 페이지가 아니라 장 단위로 스크롤하며 읽습니다. 만화 모드에서는 단어가 아니라 말풍선 전체를 누릅니다. |
