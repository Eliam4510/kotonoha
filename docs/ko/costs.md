# Claude API 비용

자신의 Claude API 키로 Kotonoha를 쓰는 비용을 2026년 11월 5일 실제 영상으로 측정한 결과입니다. 홈 화면의 **Claude 비용** 카드는 API가 보고한 토큰을 바탕으로 설치별 정확한 사용량을 보여 줍니다.

자막, 사전, 후리가나, 카드, 복습, Whisper 전사는 API를 쓰지 않으며 비용이 들지 않습니다.

이 수치는 일본어 기준입니다. 영어도 방식은 같지만 아직 측정하지 않았습니다.

## 요약

월 100달러의 기준 크레딧으로 계산하면 다음과 같습니다.

| 영상 사용 방식 | 시간당 비용 | 100달러로 월 사용 시간 |
|---|---|---|
| 자동 자막, 수정·검토·번역 포함 | 1.39 USD | 62 |
| 자동 자막, 수정·검토 포함 | 1.00 USD | 82 |
| 사람이 만든 자막, 검토·번역 포함 | 0.75 USD | 104 |
| 사람이 만든 자막, 검토 포함 | 0.36 USD | 175 |

마지막 열의 시간에는 영상 1시간당 단어 요청 30회가 포함됩니다. 검토, 수정, 번역한 내용은 저장되므로 영상을 다시 봐도 비용이 들지 않습니다.

## 측정

각 비용은 기본 모델과 노력 수준으로 작업 전후의 Claude Console 잔액을 비교해 얻었습니다. 잔액의 단위가 1센트이므로 각 수치에는 ±0.01 USD의 오차가 있습니다.

| 작업 | 영상 | 측정 비용 |
|---|---|---|
| 읽는 법, 뜻, 문법 검토 | 6:41, 사람이 만든 자막 | 0.04 USD |
| 수정과 검토 | 10:46, 자동 자막, 154줄 | 0.18 USD |
| 스페인어 번역 | 같은 영상, 150줄 | 0.07 USD |
| 문장에서의 뜻, 전체 대본을 맥락으로 | 단어 5개 | 0.03 USD |

영상 1시간당 요율은 다음과 같습니다. 수정은 두 번째 측정에서 검토를 뺀 값입니다.

| 작업 | 영상 1시간당 | 10분당 |
|---|---|---|
| 자동 자막 수정 | 0.64 USD | 0.11 USD |
| 번역 | 0.39 USD | 0.07 USD |
| 읽는 법, 뜻, 문법 검토 | 0.36 USD | 0.06 USD |

비용은 말하는 양에 따라 달라집니다. 이 영상들은 분당 약 14줄이며, 대사가 더 많은 영상은 그만큼 더 듭니다.

| 모델 | 입력 | 출력 | 캐시 읽기 | 캐시 쓰기, 5분 | 캐시 쓰기, 1시간 |

## 비용을 피하는 방법

| 조치 | 효과 |
|---|---|
| 패널은 사전으로 열립니다 | 단어에 마우스를 올려도 요청을 보내지 않습니다 |
| 답변은 단어와 문장별로 90일간 저장됩니다 | 단어를 오가거나 같은 영상으로 돌아와도 비용이 들지 않습니다 |
| 진행 중인 요청은 취소하지 않습니다 | 단어를 바꿔도 이미 지불한 것을 버리지 않습니다. 끝나서 저장되고 쓸 수 있습니다 |
| 동시에 온 같은 요청은 하나를 공유합니다 | 조바심으로 두 번 내지 않습니다 |
| 검토는 영상과 함께 진행합니다 | 영화를 10분 만에 그만두면 영화 전체 비용이 들지 않습니다 |
| 전체 대본은 요청에서 선택 사항입니다 | 요청마다 영상 전체가 아니라 맥락 40줄을 보냅니다 |

## 비용을 줄이는 방법

| 설정 | 위치 | 영상 1시간당 절약 |
|---|---|---|
| 필요할 때만 번역 | 자막 생성 | 0.39 USD |
| 재생하면서 검토하지 않기 | 자막 생성 | 0.36 USD |
| 열 때 자동 자막을 수정하지 않기 | 자막 생성 | 0.64 USD |
| 작업별로 더 작은 모델이나 낮은 노력 수준 | 설정, Claude | 작업에 따라 다르며 품질에 영향을 줄 수 있습니다 |

앞의 세 가지는 원하는 영상에서 해당 버튼으로 계속 요청할 수 있습니다.
