Demucs y demucs-web

Kotonoha usa Demucs (htdemucs), de Meta, para aislar la voz de una canción al colocar su letra con la voz.
Kotonoha uses Demucs (htdemucs), by Meta, to isolate the voice of a song when placing its lyrics with the voice.

Original: https://github.com/facebookresearch/demucs

Conversión a ONNX / ONNX conversion: timcsy, https://huggingface.co/timcsy/demucs-web-onnx (commit 92e33df),
sin cambiar sus pesos / weights unchanged.

El archivo que descarga Kotonoha / The file Kotonoha downloads:
https://github.com/Eliam4510/kotonoha/releases/download/v0.50.0/htdemucs.onnx
SHA-256 e5e425c17683f163a472462eb5f5a4ffcd11c31858d57fbd0833b012d8b88077

Lo que se hace antes y después del modelo (src/nucleo/demucs.ts) adapta el código de demucs-web, de timcsy:
What is done before and after the model (src/nucleo/demucs.ts) adapts the code of demucs-web, by timcsy:
https://github.com/timcsy/demucs-web
